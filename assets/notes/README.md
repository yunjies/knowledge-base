# 长期笔记区

本目录承载**需要跨越单次会话长期留存的笔记**——那些既不随某个项目的源码走、又不构成执行规范、但下次读到时必须还在的信息。每个笔记独立成文，以自己的文件名标识；本 README 只规定这里放什么、不放什么、以及写入时须守的形态。

## 笔记入口

- [Unraid 上的 MetaTube Server 本地运维](metatube-server-unraid.md)：维护本地 Unraid 容器与连接故障时使用；安装步骤以笔记内链接的官方说明为准。
- [DSH 远程 Web Settings 持久化问题的判别原则](dsh-trusted-web-authority-settings.md)：区分 Host 信任、页面/API 授权与客户端持久化策略时使用；具体插件部署仍查对应项目文档。
- [DSH 启动 Token 自动同步方案报告](dsh-launch-token-auto-sync.md)：参考 DSH 启动 token 同步至 Nginx 反代并为首次访问引导认证的部署设计与当前验证边界。
- [proxy 上的 Nginx + Authelia 认证入口](nginx-authelia-proxy-access.md)：维护 DSH Web 的认证反代时，查阅请求边界、运行配置取回路径、部署校验与验收方式。

## 什么进这里

判据是**这条信息的有效期是否超出产生它的那次任务**，以及**它是否有本目录之外的权威承载处**。两条同时成立才进这里：

- **跨会话仍成立**：换一个会话、换一个 agent 读到它，仍然为真且仍有用。仅对当次任务成立的中间结论不进。
- **没有别处可放**：工程本身（源码、配置、目录结构、命令输出）不承载它，`_meta/` 的执行规范与随 skill 分发的判据册（`.agents/skills/*/reference/`）不承载它，某个项目的流程文档不承载它。

## 什么不进这里

- **能从工程自行取回的事实**：取值、清单、命令输出、目录结构、配置项——写进来的话就是副本，工程一变它即分叉。写取回路径，不写取值（判据见 [_meta/agent-constraints.md](../../_meta/agent-constraints.md) 的 C04）。
- **执行规范**：约束 agent 应当如何行动的条目归对应规范册——不随 skill 分发的归 `_meta/` 下文档，随 skill 分发的判据册（文档撰写、流程类文档撰写、规则卡片撰写）归 `.agents/skills/*/reference/`。两处都不在此另立一套。
- **单个项目的流程与结构**：归该项目目录下的流程文档（如 [home-media-pilot](../projects/home-media-pilot/feature-flow.md)），此处不放它的副本。
- **单个项目的部署与使用方式**：同样归该项目目录下的部署文档（`<项目>/deploy.md`），此处不放它的副本；只有与任何单个项目都无关的部署与运维事实才进本目录。
- **来历叙事**：变更记录、提交历史、工单与纪要存档。它们解释事物如何变成今天的样子，不证明它今天应当这样（同上 C01、C05）。

## 写入形态

- **一笔记一文件**，文件名为该笔记的标题，与本目录内其它文件不重名；文件不再需要时整篇删除，不做"已废弃"式的留档。
- **标题即结论面**：H1 之后的首段说明这条笔记要在什么问题上被用到，使读者只读标题与首段即可判断是否与自己相关。
- **写明适用范围**：这条笔记在什么条件下成立、什么条件下失效；无条件的断言与有条件的断言须能分辨。
- **指向事实源而非复述**：涉及可自行取回的事实，写取回它的命令或路径。
- **不含密钥与凭据**：真实环境文件由仓库根 `.gitignore` 排除，本目录同样不放任何凭据、令牌或内网地址。
