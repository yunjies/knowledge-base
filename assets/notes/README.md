# 长期笔记

本 README 是 `main` 上的通用边界与写入方法；`main` 只承载此类结构与方法，不承载具体笔记内容。每条笔记文件都是内容，必须留在需求方确认的非 `main` 内容分支；未确认分支时先询问，不默认使用 `main` 或当前分支。

本目录只承载需要跨会话留存、且没有更合适归属位置的通用笔记。笔记须在不同会话中仍成立并有用；仅能从工程本身取回的事实、执行规范、过程记录，以及只适用于单一项目的内容不属于此处。

## 写入边界

- 将每条相对独立的长期结论写成单独文档，标题应概括其主题。
- 写入前确认内容不能由权威来源直接取回，也不应归入其他文档或流程说明。
- 只记录跨会话仍有效的结论与必要背景，不记录变更来历、会话纪要或已结束事项的过程留档。
- 使用通用表述；不得把项目专属流程、结构或资料复制到此处。
- 内容不再需要时删除整篇文档，不以“已废弃”条目留存。

本 README 说明本目录的通用边界与写入方式，不提供具体笔记目录或索引。
