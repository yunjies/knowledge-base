# DSH Docker domain

This domain covers a standalone DSH Web container, its runtime DSH version selector, persistent profile behavior, and its optional connection to a separate TTSwitch service on a private Docker network.

## Authority

The `docker-for-dsh` project repository is the authority for the Dockerfile, startup scripts, GitHub Actions workflow, Unraid template, and project tests. This domain records only the DSH-specific deployment contract and registration metadata; it does not copy project source or user-specific appdata.
