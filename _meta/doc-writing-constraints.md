# 文档撰写规范

本文档是面向知识库与指令类文档的撰写规范，按条目组织；未枚举情形由各条目主句内嵌的判据裁决。

## D01 · 指路性引用必须可跳转

**指路性引用一律写成 Markdown 链接 `[显示名](目标路径)`**，不得裸写文件名或路径。判据：句子的功能是让读者**前往**另一处（"见 X""先读 X""定义在 X"）即为指路性引用——读者必须能从引用处一步到达被引对象；裸文件名迫使读者自行检索，且引用失效时无信号（死链可被工具发现，过期裸文本静默）。显示名用被引对象的文件名或职能名（如"根 AGENTS.md"），不用"这里""见此"——显示名丢失定位信息时，链接只是把检索负担换了形态。

**边界与例外**

- **名词性提及放行**：被引对象仅作为句中讨论对象出现（"本册与 X 各管一域"），读者不跳转也能完整理解句义的，裸文本不违规。
- **路径相对引用者自身书写**：绝对路径锚定本机目录布局，工程迁移即断。同文档章节引用用锚点链接，且**以渲染环境确能生成标题锚点为前提**——锚点不可达时锚链是伪链（点击无处可去），退化为文件级链接或职能名裸文本。
- **非文件目标无从造链**：引用对象不可寻址（口头约定、对话记录）时裸文本即可——判据本就是"能否一步到达"，本来到不了的对象造不出链。
- **存量归位**：本条生效前的存量引用，随其所在文档的下次修订归位——格式约束作用于持续存在的文档存量，须给归位路径，而非要求一次性全库整改。

## D02 · 正文不转述可自行取回的事实

**正文不把读者能从原始信息自行取回的事实写成结论**（计数、体积、条数、处数）；此时要表达该事实，应给出**取回路径**——读者据此能现取、且随被观测对象一同演进的表述——而非取值本身。判据有两条，均在动笔当下可核验：**删除测试**——删掉这段文字，读者能否自行取回同一事实？能，则此处不该有它；**同步义务测试**——该事实变更时，负有同步义务的是工程里那份原始信息，还是这处文字？是前者，写下的即是副本。命令、指针与成员清单与被观测对象同源，不会在无人编辑文档时失真。

**边界与例外**

- **决策不受管辖**：由设计导出的常量（上限、时间窗、阈值）与取舍结论是决策而非观测——原始信息只记录它取值几何，不记录它是决定；改它必经一次设计决定，该决定必然连同实现与测试一起落地。
- **值可得而权威不可得时必须写**：从原始信息能读出取值、读不出"该取值即权威、不得擅改"时，该契约必须写出来——这是文字相对原始信息的净增量；界线是权威归属，不是读者能否取到值。
- **移值不得删事实**：修剪时把取值改写为取回路径，不要连同其所在的事实子句一起删除——删掉路径，读者便无从获得该事实。
- **载体只是样张**：禁令锚在"权威归属"，不在数字形态；标识符、序号、不随实现漂移的路径片段不受此约束。
- **让位**：取回路径的具体形态、样例与机器守护由[根 AGENTS.md](../AGENTS.md) 规定并在该处维护，本册不另立细则、不重复其清单；两处表述不一致时以根指令文档为准。

## D03 · 正文不引用外部记录的条目

**正文不得把事实表述为对另一份记录中某条目的引用**（编号、轮次标签、账本条目）：该引用使本文档成为那份记录的索引副本，两边各自演进即分叉，记录一经移动、重建或废弃，引用即成孤儿。判据：**把事实直接写出来**——由设计导出的事实，设计不变则恒真，与该记录当前是否存在无关。

**边界与例外**

- **可解析的归属放行**：被引对象本身是已提交且稳定的文档时（外部标准的条款、拥有自身编号的已提交文档），引用按设计在本文档之外解析，不构成索引副本。
- **说明记录已不存在不是引用**：解释某记录被移除时必然提到它，该句陈述的是现状，不是索引。
- **判据与记录存废无关**：索引重建不构成解禁理由——正文仍直接陈述事实，检索归索引承担。
- **让位**：本条与其细则的维护归属同 D02，冲突时以根指令文档为准。

## D04 · 正文陈述当前状态，不叙述变更

**正文描述事物当下的样子，不描述它如何变成这样**——变更叙述（"以前是 X""不再 Y""旧版 Z""本次起改为 W"）与版本戳（"v1""本版""截至目前"）均在禁列。判据：文档的参照系是它自身，读者读到的应是一个状态而非一段历史；变更过程自有承载它的记录，正文复述它既产生第二事实源，又随下一次改动静默失配。

**边界与例外**

- **现在时反事实放行**：`没有 X 则 Y 发生` 陈述的是当前设计的失败模式，主语是当前实现而非过去状态，不属变更叙述。
- **运行时的新旧不是变更历史**：命名交接期间两个同时活动的对象（`旧连接排空后新连接才接收`）用的是生命周期词汇，不是仓库状态。
- **运行时可判定的标识符放行**：随格式或协议版本而异的兼容分支，其版本标识供运行时判定，不是戳记。

## D05 · 正文不采纳会话视角

**正文不得以产生它的那次会话为参照系**——不引用"本次/上次改动"、改动在系列中的位置、评审的结论与轮次、草稿的修订序号。判据：**读者处在文档当前版本上，无法访问任何会话记录、讨论串或未提交草稿，正文中的每个引用与断言都必须能被这样的读者独立解析与核实**。

**边界与例外**

- **可解析的外部引用放行**：指向公开可寻址对象的引用（缺陷单编号、外部标准条款）按设计在文档之外解析；被禁的是只有会话参与者才认得的坐标。
- **流程文档正当使用流程词汇**：讨论流程本身的文档可以使用"提交""评审"等词——禁令针对的是文档采纳了某次改动的视角，不是词汇本身。
- **体裁槽位放行**：决策记录中记载被否决方案的章节是认可的归宿；被禁的是把评审者与轮次写进理由。
- **可解析只满足门槛**：独立可解析不豁免本册其他条目——一段可解析的变更叙述仍归本册"陈述当前状态"条管辖，两判据正交，不得以"读者查得到"规避。

## D06 · 正文陈述契约，不承载推导与辩护

**正文只承载读者无法从对象本身重建的契约与不变量**，不承载推导过程与自我辩护——步骤复述（"先 X 再 Y 最后 Z"）、对显然分支的证明、面向异议的辩护（"这是正确的，因为…""它只是…"）均在禁列。判据：正文的受众是维护者，不是写下它时的评审者——推导过程读者能自行重走，辩护回应的是当前版本上无人提出的异议；两者只增加阅读量而不增加可核实的事实。

**边界与例外**

- **只删推导，不删结论**：结论无法从对象本身重建时（不变量、失败模式、耦合关系），它是本条要保留的契约。
- **工具消费者的理由放行**：写给工具的指令所附理由（抑制指令、忽略说明）有代码之外的消费者，不属辩护。
- **来源标记放行**：数值的来源标记承载"这是观测而非定义"的信息，删掉它会使读者在值变化时无从复核。
- **契约就近自表达**：删去推导后仍无法自表达的，改对象本身（命名、结构），不在正文里补回论证。

## D07 · 不确定表述必须有归属或边界

**正文不得留下无承担者的模糊判断**（"暂时够用""应该可以""以后再优化"）——判据：模糊判断没有承担者，无人负责兑现或复核，它只会让读者误以为该问题已被考虑过；未决事项写成**指明承担者与动作**的待办标记，估计值改写为**可判定的边界**。

**边界与例外**

- **带归属的待办是归宿**：指明承担者与动作的标记已给出归属，不属模糊表述。
- **观测值须带来源**：估计值写明来源（实测、上限、规格）才可写；缺来源标记时它被读成定义，值一变即无人复核。
- **边界优于精度**：写不出确切值时给出判据——何种情形失败、失败后如何表现——不写无边际的形容词。

## D08 · 行文语言不得混用

**同一文档的行文语言必须统一**，不得混入未整理的工作语言片段与会话分隔符。判据：混用是誊写残留，读者无法判断某片段是正文还是未清理的会话产物。

**边界与例外**

- **标识符不译**：代码、命令、路径、第三方 API 名称按原样保留，不算语言混用。
- **按设计在文档之外解析的来源放行**：外部标准的原文标题、外部工具的界面名保留原语言。

## D09 · 修订正文不得改变命题

**修订正文不得改变其承载的命题**——动手前先枚举该段落承载的每条断言，逐条处置：能由对象本身重建的删除，其余改写成在文档当前版本上独立成立的表述。判据：每句话都是一个断言，删句与改句都会改变断言集合，而"读起来像泄漏"不等于"不承载命题"。

**边界与例外**

- **只删表述，不删断言**：记录性坐标、视角与辩护可删，被它们携带的事实必须重述后保留——连同记录一起删掉断言是过度纠正。
- **情态不得翻转**：义务（"待迁移"）不是认可（"已认可"），假设（"若存在 X 则…"）不是既成事实——改写保持原句的情态强度。
- **来源不得随值丢失**：保留观测值时一并保留其来源标记，否则观测被读成定义。
- **零命题片段整段删除**：纯坐标（编号、轮次、分隔符）不承载命题，删除而非改写。
- **改动落在源头**：同一事实由生成过程产生时，修源并重新生成，不手改产物——手改产物会在下次生成时丢失。
