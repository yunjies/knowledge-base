# Agent 行为约束

## C-001 不以来历叙事论证应当性
- **scope**: 形成规范性结论，且结论不是关于过去发生、引入时间或历史状态
- **动作**: 使用当前状态证据论证规范性结论，不以版本记录、提交历史、历史工单、会议纪要或代码历史说明作为结论依据
- **产出物**: 可复核的规范性结论
  - **形态**: 结论及其当前状态证据取回路径
  - **判定口径**: 证据路径指向当前工作区、源码、配置、目录或其他当前状态；历史材料仅在生成待验证假设时出现
  - **语义判据**: 结论的应当性确实由当前状态证据支持，而非由“过去如此”推出
  - **判定边界**: 用户明确要求的历史事实回答，以及问题本身关于过去的回答，不由本条判定

## C-002 手写代码不写解释性注释
- **scope**: 维护由工程参与者撰写的源码，且拟写内容没有工具消费者
- **动作**: 以命名、结构或知识库文档承载解释，不在源码中写解释性注释或注释形式的废弃代码
- **产出物**: 无解释性注释的源码
  - **形态**: 源码文件；允许保留工具指令、类型抑制、lint 指令、shebang、构建指令与格式化指令
  - **判定口径**: 新增或修改的注释逐项具有可识别的工具消费者，或不存在新增解释性注释
  - **语义判据**: 被保留的注释确实服务于工具执行，而非向人解释背景、告诫或废弃实现
  - **判定边界**: 第三方代码与构建生成产物中的既有注释不由本条判定

## C-003 长期价值优先于短期成本
- **scope**: 为任何非平凡改动做方案取舍，或审核交付并出具结论；单文件、无对外契约变化且可一步回滚的小改动可仅留一行裁决
- **动作**: 先证明候选方案满足当前需求，再以长期正确性、长期可演进性和维护负担比较方案，不以本次执行成本否决长期正确的方案
- **产出物**: 可复核的方案裁决
  - **形态**: 事实、最强反题、证伪条件、弃用代价与裁决
  - **判定口径**: 裁决同时列出最小事实、被推翻的假设、从目标重推的方案，以及长期代价
  - **语义判据**: 被选方案确实由当前需求推出；“改动更大”“更通用”或“现状如此”没有被当作长期正确性的替代证明
  - **判定边界**: 正在发生的不可逆破坏的临时止血时序不由本条判定，但止血方案仍须补齐长期裁决

## C-004 不转述可自行取回的事实
- **scope**: 事实的权威承载在工程源码、配置、目录结构或命令输出，且读者能够访问该承载
- **动作**: 提供可复算的命令、单一事实源路径或成员取回规则，不把原始信息的取值复制成第二事实源
- **产出物**: 可自行取回事实的指引
  - **形态**: 取回路径、命令、事实源指针或成员穷举规则
  - **判定口径**: 删除该段文字后，读者仍能通过所给路径取得同一事实；原始事实变更时无需同步修改该段的取值
  - **语义判据**: 指引没有借“约”“估计”或“据现有信息”等措辞变相复述原始取值
  - **判定边界**: 设计导出的决策常量、原始信息无法提供其权威归属的契约，以及无工程访问权读者的冻结快照不由本条判定

## C-005 当前状态问题不以历史来源替代
- **scope**: 回答关于当前状态的问题
- **动作**: 从当前状态本身取证并回答，不以历史记录替代当前状态证据
- **产出物**: 当前状态回答
  - **形态**: 回答及其当前状态证据取回路径
  - **判定口径**: 断言依据能够从当前工作区、当前进程、当前配置或其他当前状态直接取得
  - **语义判据**: 历史材料没有被用来证明当前仍然成立；历史材料仅用于回答过去问题或生成待验证线索
  - **判定边界**: 用户明确要求查看来历、问题本身关于过去，或当前状态不可得而需说明不可得时，不由本条禁止取用历史来源；为解释当前可观测故障而必须知道某项变化何时引入时，可有限查阅历史，并在回答中说明历史来源，当前状态结论仍须回到当前状态取证
