# Agent 行为约束

本文档是 agent 执行规范，按条目组织；未枚举情形由各条目主句内嵌的判据裁决。

## C01 · 不以来历叙事论证应当性

**不以"来历叙事"作为规范性结论的论据**：来历指一切叙述"过去发生/决定了什么"的记录——版本变更记录（changelog、发布说明）、提交历史（git log/show/blame）、历史工单与缺陷记录、会议纪要与讨论存档、代码内以文字标注的历史说明。不得以"当年如此"论证"现在应当如此"；来历至多解释事物如何变成今天的样子，不证明它今天应当这样。

**边界与例外**

- **事实性使用合法**：回答"何时引入、是否发生过、当时如何"这类事实性问题、或生成排查线索时，来历可查；但规范性结论须由现状证据独立支撑，不得以来历本身作结。
- **当前工作区状态合法**：工作区状态类命令（git status、git diff 等）描述现在而非过去，不属于来历叙事。
- **授权不作用于推理层**：用户要求查看来历，只授权了取来源（见 C05），不使"当年如此故现在应当"成立——论证的合法性与是否获准调取正交。
- **绕行封堵**：以任何载体、任何途径获取来历叙事用于论证，同罪。禁令锚在**结论类型**上，载体（git、changelog、工单、纪要……）只是样张。

## C02 · 手写代码不写注释

**由工程参与者撰写或维护的源码，不写注释**（任何语言的注释语法——行注释、块注释、文档注释——均在列）：判据锚在注释的**消费者**上，注释唯一合法的承载是给工具的指令；写给人的解释性内容不进代码——设计背景与告诫写入知识库，能以命名与结构自表达的，优先改代码本身。以注释形式保留的废弃代码同禁：它既非指令也非解释，只是无人守护的陈旧内容。

**边界与例外**

- **指令性注释合法**：类型抑制、lint 指令、shebang、构建与格式化指令等存在人以外的真实消费者的注释，是可执行行为的一部分，不在禁列——判据是"是否有工具消费者"，不是语法形态。
- **非己方代码不受管辖**：拷入的第三方代码与构建生成产物中的既有注释，不因本条而必须清除；本条只约束自己撰写或维护的代码。
- **文本巧合不是注释**：字符串字面量、正则等上下文中出现的注释语法字符不触发本条——禁令锚在"以注释语法承载解释性内容"的用途上，不在文本匹配。

## C03 · 长期价值优先于成本

短期执行成本无权否决长期正确的方案；长期维护负担、复杂度债务与演进能力才是成本的主要分量。

**边界与例外**

- **归类判据**：同一动作同时呈现两侧时——省下本次投入属短期，不做该投入而累积的负担属长期——按**后续是否重复收取**归类，不按本次付出多少归类。轴由主句给出，落点由本条裁决。
- **"长期正确"不由本条证明**：本条只赋予**已论证为长期正确**的方案以优先地位；改动范围大、抽象层多、设计更通用，均不导出长期正确。判据是该改动能否由当前需求导出。
- **紧急改变的是论证时序，不是标准**：处置可先做、论证后补，但处置本身仍须经长期正确性裁决通过；以"来不及论证""先上线再说"要求放行，无效。

## C04 · 不转述可自行取回的事实

**不把读者能从原始信息自行取回的事实写成结论**：凡事实的权威承载在工程本身（源码、配置、目录结构、命令输出）时，只写**取回它的路径**——可复算的命令、指向该源的指针、成员穷举规则——不写它的取值。判据有两条，均在动笔当下可核验：**删除测试**——删掉这段文字，读者能否自行取回同一事实？能，则此处不该有它；**同步义务测试**——该事实变更时，负有同步义务的是工程里那份原始信息，还是这处文字？是前者，写下的即是副本。数字与计数只是副本最常见的载体，不是禁令的运行范围。

**边界与例外**

- **决策不是观测**：由设计导出的常量（上限、时间窗、阈值）与由设计导出的取舍结论，其权威不在原始信息里——原始信息只记录它取值几何，不记录它是决定；改它必经一次设计决定，该决定必然连同实现与测试一起落地，不存在"文字未动而值已变"的时刻。
- **值可得而权威不可得时必须写**：从原始信息能读出取值、读不出"该取值即权威、不得擅改"时，该契约必须写出来——这是文字相对原始信息的净增量；与本条的界线是权威归属，不是读者能否取到值。
- **对外部读者按快照冻结**：无工程访问权的读者（发布物、归档）读到的复述是信息而非副本，须标出来源与冻结时刻。
- **绕行封堵**：以"约""估计""据现有信息"等措辞复述同一取值，同罪。禁令锚在"转述原始信息"上，措辞只是样张。
- **修剪不得删事实**：把取值改写为取回路径时，不连同该事实一起删除——删掉路径，读者便无从获得它。

## C05 · 不以历史来源替代当前状态

**回答关于当前状态的问题，依据须取自当前状态本身，不得以叙述过去的记录替代**：判据是**该断言的依据能否从当前状态直接取回**——能取回却改用叙述过去的记录者，即违规；当前状态不可得时，才落到例外。禁令锚在**来源选择**上，历史记录的形态（命令、托管平台界面、归档文档）只是样张。

**边界与例外**

- **用户明确要求**：用户点名要查看来历时，可调取并转述，回答里说明数据来源即可。
- **问题本身就是关于过去的**：回答"何时引入、是否发生过、当时如何"，或为解释当前可观测的失败而须知道某变更何时引入时，历史记录是该问题本身的正当来源；范围限于该问题所需，不得由它扩张为对当前状态的依据。
- **描述现在的查询是主句要求的来源**：工作区状态、现状差异这类查询产出的是当前状态，正在主句要求之列，不在禁列。
- **历史可作线索，不可作依据**：历史中出现的现象可用于生成待验证假设，但假设的结论仍须回到当前状态取证。
- **绕行封堵**：以任何载体（命令行、托管平台界面、接口、归档文档）取历史记录替代当前状态，同罪。禁令锚在来源选择上，载体只是样张。
