# 文档撰写规范

## D-01 指路性引用必须可跳转

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 正文中存在功能为让读者前往另一处的指路性引用
- **动作**: 把每处指路性引用改写成 Markdown 链接，存量引用随其所在文档的下次修订归位
- **产出物**: 文档正文中的引用标记
  - **形态**: 每处引用形如 `[显示名](目标路径)`；显示名取被引对象的文件名或职能名，不取"这里"、"见此"这类失定位信息的词；目标路径相对引用者自身书写，同文档章节引用用锚点链接
  - **判定口径**: 每处引用匹配 `\[[^\]]+\]\([^)]+\)`；显示名不为"这里""见此"；目标路径可解析到现存对象，不留死链；目标路径以 `.` 或字母开头，不以 `/` 开头——前导斜杠会把目标解析到本文档所在位置之外；仓库内目标缺失时按失败处理并报出该路径，不静默留下一处无从跳转的引用
  - **语义判据**: 读者从引用处能否一步到达被引对象；句子功能是让读者前往他处即属指路性引用，仅作名词性提及而读者不跳转也能完整理解句义的，不属于本条
  - **判定边界**: 显示名与目标对象是否相符不由本条判定；非文件目标无从造链者不由本条判定；锚点不可达时退化为文件级链接或职能名裸文本者不由本条判定

## D-02 正文不转述可自行取回的事实

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 正文拟写入读者能从原始信息自行取回的事实
- **动作**: 在正文写入该事实的取回路径，或按值可得而权威不可得、由设计导出两种情形改写为对应形态
- **产出物**: 承载该事实的正文表述
  - **形态**: 事实表述为与被观测对象同源的取回路径，或为值可得而权威不可得时的契约，或为由设计导出的取值
  - **判定口径**: 对每处事实表述施加删除测试与同步义务测试——删掉该段文字后读者仍能自行取回同一事实者，判为转述；该事实变更时负有同步义务者是工程里的原始信息者，判为副本；同一事实的第二种表示同判，其高发形态是镜像同一事实的两处文字，以及跨生命周期两个平面各自记一份的同一取值；同一事实有多个可能来源时，其归属方取权威最强的那个原始信息，而非既有的另一处文字
  - **语义判据**: 被写入的取值是否即权威、不得擅改——权威归属在工程原始信息之外时，该契约必须写出
  - **判定边界**: 由设计导出的常量与取舍结论、其权威不可从原始信息读出而必须写出的契约、标识符与序号、不随实现漂移的路径片段，均不由本条判定；调用方或维护者在使用点需要的契约事实（行为、失败、归属、后果）不属可自行取回之列，须就地写明，以链接取代它或以"一个解释只有一处归属"为由删去它，不由本条判为合规；以穷举清单复述另一处已载的成员（接口目录、字段清单、事件枚举）同判为转述，成员的真相应留在其归属方并由读者按需取回；取回路径取命令、指针还是成员穷举中的哪种形态，由承载该事实的对象自身决定，不由本条判定；架构、理由、算法、历史与扩展示例属他处拥有的解释，须以链接给出而不在使用点复述；由他方拥有且稳定的文本以引用给出，不复抄一份

## D-03 正文不引用外部记录的条目

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 正文拟以另一份记录中的编号、轮次标签或账本条目表述事实
- **动作**: 把该事实按其设计直接写出，或按记录已不存在、引用可解析两种情形改写
- **产出物**: 承载该事实的正文表述
  - **形态**: 事实直接成句，不借另一份记录的条目编号、轮次标签或账本条目定位
  - **判定口径**: 正文不出现指向另一份记录条目的编号、轮次标签或账本条目引用
  - **语义判据**: 该事实是否由设计导出——设计不变则恒真，与该记录当前是否存在无关；该引用是否使本文档成为那份记录的索引副本
  - **判定边界**: 被引对象本身是已提交且稳定的文档（外部标准条款、拥有自身编号的已提交文档）的引用，以及说明某记录已不存在时必然提到它的句子，均不由本条判定；被引记录的索引被重建不构成本条的解禁理由——引用的问题在于本文档成了那份记录的索引副本，与该记录当前是否可查无关；指向公开可寻址的缺陷单或任务单条目的引用，其在文档当前版本上可解析者不由本条判定

## D-04 正文陈述当前状态，不叙述变更

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 正文拟写描述事物如何变成当下样子的变更叙述或版本戳
- **动作**: 把该表述改写为对事物当下样子的陈述
- **产出物**: 承载该事实的正文表述
  - **形态**: 表述的参照系是文档自身，读者读到的是状态而非一段历史
  - **判定口径**: 正文不出现变更叙述与版本戳——变更叙述的记号取"以前是""不再""旧版""本次起改为""曾用于""重命名""移出"一类，版本戳取"v1""本版""截至目前""本次迭代""暂定""路线图"一类
  - **语义判据**: 该表述陈述的是当前设计还是过去状态——`没有 X 则 Y 发生` 一类现在时反事实，其主语是当前实现的失败模式；已修复的缺陷按此改写为现在时反事实，不写修复史
  - **判定边界**: 现在时反事实、命名交接期间两个同时活动对象所用的生命周期词汇、供运行时判定的格式或协议版本标识，均不由本条判定；为论证反对意见而作的历史对比，其正当承载处是决策记录本身，不由本条判定——本条判定的是正文有没有把历史当作当下状态的依据；运行时的自然时间与已记录的时间戳、既有的命令输出样本，其语气属运行时事实而非版本戳，不由本条判定

## D-05 正文不采纳会话视角

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 正文拟出现仅该次会话参与者可解析的坐标
- **动作**: 把该坐标改写为读者在文档当前版本上可独立解析与核实的表述
- **产出物**: 承载该断言的正文表述
  - **形态**: 每条引用与断言都被写成读者不访问会话记录、讨论串与草稿即可独立解析与核实
  - **判定口径**: 以文档当前版本为唯一参照系逐句追问——不访问任何会话记录的读者能否解析该引用并核实该断言；正文不出现"本次/上次改动"、改动在系列中的位置、评审结论与轮次、草稿修订序号
  - **语义判据**: 读者处在文档当前版本上能否独立解析与核实该断言；工具义的"曾用于"、流程文档本身的"提交""评审"词汇、作为协议或路径片段的版本号，均不构成会话坐标
  - **判定边界**: 指向公开可寻址对象的引用、讨论流程本身的文档所用的流程词汇、决策记录中记载被否决方案的章节，均不由本条判定；独立可解析不豁免本册其他条目

## D-06 正文陈述契约，不承载推导与辩护

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 正文拟写入读者能从对象本身重建的推导过程或面向异议的辩护
- **动作**: 删除推导与辩护，仅保留结论，或按契约就近自表达改变对象本身
- **产出物**: 承载该事实的正文表述
  - **形态**: 正文只承载读者无法从对象本身重建的契约与不变量
  - **判定口径**: 正文不出现步骤复述、对显然分支的证明、面向异议的辩护
  - **语义判据**: 该结论能否从对象本身重建——不变量、失败模式、耦合关系无法重建时，它即本条要保留的契约；推导过程读者能自行重走，辩护回应的是当前版本上无人提出的异议；面向评审人的正确性主张改写为不变量或测试，不引人不引时序
  - **判定边界**: 写给工具的指令所附理由、数值的来源标记，均不由本条判定；改变既有契约的实现细节不属可略去的推导，须保留——该细节是否改变契约是唯一判据，是否属实现细节不是；决策记录中作为该体裁必需内容的反论与代价归 [D-22](#d-22-决策记录须承载反论代价与可观察验收面)；记录中不锚定该决策的规划清单不属须保留的证据

## D-07 不确定表述必须有归属或边界

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 正文拟留下无承担者的模糊判断
- **动作**: 把未决事项改写为指明承担者与动作的待办标记，把估计值改写为可判定的边界
- **产出物**: 承载该判断的正文表述
  - **形态**: 未决事项写成含承担者与动作的标记，估计值写成含来源标记的观测值或可判定的边界
  - **判定口径**: 正文不出现无承担者的模糊判断（"暂时够用""应该可以""以后再优化""大致足够""先这样"）；估计值均带来源标记
  - **语义判据**: 该判断是否有承担者负责兑现或复核——无承担者时读者会误以为该问题已被考虑过；写不出确切值时是否给出可判定的失败边界（何种情形失败、失败后如何表现），而非无边际的形容词；实测数值的来源标记承载"这是观测而非定义"的信息，删去后读者在值变化时无从复核
  - **判定边界**: 含承担者与动作的待办标记已给出归属，不由本条判定

## D-08 行文语言不得混用

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 同一文档的行文语言
- **动作**: 把未整理的工作语言片段与会话分隔符改写为文档行文语言的正文
- **产出物**: 文档正文
  - **形态**: 全文行文语言统一，无未整理的工作语言片段与会话分隔符
  - **判定口径**: 正文不出现会话分隔符与未整理的工作语言片段——中文行文中混入的外文工作片段以"设计稿""评审""上一轮""旧版""老的""不再""以前""遗留""私有""端"一类词面为记号
  - **语义判据**: 读者能否判断某片段是正文还是未清理的会话产物；"本版本"是正常名词，被禁的是作为版本印记的裸"本版"
  - **判定边界**: 代码、命令、路径、第三方 API 名称，以及按设计在文档之外解析的外部标准原文标题与外部工具界面名，均不由本条判定

## D-09 修订正文不得改变命题

- **when**: 修订知识库与指令类文档的正文
- **scope**: 正文中含有记录性坐标、会话视角或辩护的表述
- **动作**: 按序执行（步间有数据依赖）
  - ① 枚举该段落承载的每条断言
  - ② 以该枚举为输入，删除坐标、视角与辩护，并保留其余断言；零命题片段整段删除
- **产出物**: 修订后的正文表述
  - **形态**: 每处改写都在文档当前版本上独立成立，情态强度与原句一致，观测值随其来源保留
  - **判定口径**: 逐项核对五类必保事实无丢失——执行主体与动作、条件与时机与顺序、情态（必须／可以／绝不）、否定性保证与例外、归属与副作用与失败模式与后果；修订后不出现修订前枚举之外的断言；纯坐标片段整段删除而非改写
  - **语义判据**: 每条被删或改写的断言在修订后能否从对象本身重建或已被重述保留；承载事实的分句须先重述后删除，不得只删不述；四类过度矫正须避免——义务不得翻转成背书（"待迁移"不是"已认可"）、假设不得提升为已交付（须显式标注为假设）、整句承载多个命题时只删分句不删整句、保住观测数字须一并保住其来源标记
  - **判定边界**: 记录性坐标、会话视角与自我辩护是否可删不由本条判定——其可否出现归 [D-03](#d-03-正文不引用外部记录的条目)、[D-05](#d-05-正文不采纳会话视角)、[D-06](#d-06-正文陈述契约不承载推导与辩护)，本条只判定删除后断言是否仍在；同一事实由生成过程产生时，改动落在源头并重新生成，产物本身的手改不由本条判定

## D-10 正文写到保住承重约定为止

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 正文中的每处表述
- **动作**: 以保住承重约定为下限、以删除推理叙述与重复装饰为上限撰写正文
- **产出物**: 正文
  - **形态**: 每条承重约定在位，推理叙述、重复与装饰已清除
  - **判定口径**: 逐句追问该句被谁依赖、依赖哪一类——能指出依赖者的即承重约定，其形态为义务、不变量、前置条件、后置条件或兼容性承诺
  - **语义判据**: 该句承载的是承重约定还是装饰——无人依赖的陈述不构成约定，删去它不损失任何读者需要的行为
  - **判定边界**: 哪些表述属推导与辩护归 [D-06](#d-06-正文陈述契约不承载推导与辩护)；篇幅的减少是否构成删改依据归 [D-11](#d-11-精简正文不得以篇幅为判据)；修订后命题是否仍在归 [D-09](#d-09-修订正文不得改变命题)；到达使用者或模型的措辞本身即行为，删改它等同改行为，其证据要求归 [D-19](#d-19-操作性断言须以运行为证据)；能令一处抽象限制在操作层面变清晰的那个具体例子不属装饰

## D-11 精简正文不得以篇幅为判据

- **模态**: must_not
- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 正文的精简与删改
- **动作**: 以篇幅的减少为由删除或改写正文表述
- **产出物**: 修订后的正文
  - **形态**: 每处删改都以"其承载的断言已在别处保留且结果更清晰"为依据
  - **判定口径**: 逐分句核对存活；篇幅的减少本身不构成依据
  - **语义判据**: 删改后结果是否更清晰——更短但丢掉后果与区分、结构未改善者即更差
  - **判定边界**: 断言是否存活归 [D-09](#d-09-修订正文不得改变命题)；哪些表述承重归 [D-10](#d-10-正文写到保住承重约定为止)

## D-12 独立展示的正文片段须自足

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 会脱离其上下文被单独读取或展示的正文片段
- **动作**: 把该片段写成不依赖后文即可成立的表述
- **产出物**: 该片段
  - **形态**: 只读该片段即可获得其展示面所需的全部约定，不依赖后文才成立
  - **判定口径**: 把该片段单独取出，其承重约定不因脱离上下文而失效；被生成过程抽取时，抽取面所需的约定在该片段内闭合
  - **语义判据**: 该片段是否会被单独展示或抽取——文档目录、技能索引一类展示面只取该片段，读者与执行者据此判断其内容
  - **判定边界**: 不脱离上下文展示的正文、以及该片段是否承重，均归 [D-10](#d-10-正文写到保住承重约定为止)

## D-13 术语使用前核对是否有更确切的表达

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 正文中的抽象术语
- **动作**: 使用抽象术语前核对是否存在更确切的技术对象名
- **产出物**: 正文中的术语
  - **形态**: 命中确切技术对象时保留该术语；存在更确切的表达时改用它
  - **判定口径**: 沿确切规则、接口、字段集合、类型、校验、时点、组件划分、失败情形逐项核对是否有更确切的表达
  - **语义判据**: 该术语指向的是确切技术对象还是无对象的泛称；可检索的机制名与承载实义的情态、时间、否定强调是承重内容，须保留
  - **判定边界**: 本条不产出禁用词表，也不把术语本身列为禁用词

## D-14 指令类文档须写明行为护栏与范围限制

- **when**: 撰写、修订或审阅指令类文档的正文
- **scope**: 技能指令与 agent 指令的正文
- **动作**: 在指令类文档中写明行为护栏与显式范围限制
- **产出物**: 该文档的范围限制与护栏表述
  - **形态**: 显式写出该文档管什么、不管什么，以及执行者不得越过的行为边界
  - **判定口径**: 文档中存在显式的范围限制语句
  - **语义判据**: 该限制是否决定执行者如何应用该文档——决定者属护栏，不得以精简重复说服内容为由删除
  - **判定边界**: 非指令类文档不由本条判定，其必备内容归 [D-23](#d-23-面向使用者的说明须承载消费方约定) 与 [D-24](#d-24-操作手册须含前置条件与可观察验证)；本条的护栏与范围限制成句写出，其承载的工作流细则以链接给出而不在本处展开

## D-15 正文点明执行主体与动作

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 正文中承载指令、步骤或行为描述的表述
- **动作**: 在承载指令的表述中点明执行主体与动作
- **产出物**: 承载该指令的表述
  - **形态**: 主体明确到可指认，动作以直接动词承载，不以名词化短语替代精确动词
  - **判定口径**: 每条指令表述可指认其执行主体；存在精确动词时不以名词化表达承载该动作
  - **语义判据**: 主体未点明时读者是否仍须自行推断谁执行该动作；主体重要时优先主动语态
  - **判定边界**: 叙述性而非指令性的表述不由本条判定；单主体文档缺省取文档默认主体者不由本条判定

## D-16 一句只承载一条指令或一组紧密条件

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 单个句子中并列承载多条指令、多个条件或多条独立断言
- **动作**: 按句拆分，把并列的指令与条件分置于各句；达到三项及以上时改用列表
- **产出物**: 拆分后的正文
  - **形态**: 每句承载一条指令或一组紧密耦合的条件；三项及以上的条件或步骤以列表承载
  - **判定口径**: 逐句计数其中彼此独立的指令与条件，达到三项及以上者检查其是否以列表承载
  - **语义判据**: 拆分是否掩盖了条件之间的关系——拆分会使某项条件或关系被掩盖时保留原句
  - **判定边界**: 篇幅的增减不由本条判定，归 [D-11](#d-11-精简正文不得以篇幅为判据)

## D-17 同一概念在全文只用一个术语

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 正文中表述同一概念的多个词面
- **动作**: 为该概念选定一个术语并通篇沿用
- **产出物**: 承载该概念的正文表述
  - **形态**: 同一概念在全文用一个固定词面，不为求变化而轮换同义词
  - **判定口径**: 同一概念在全文的命名唯一，术语首次出现后可按该词面稳定检索
  - **语义判据**: 两个词面是否指同一概念——确属不同概念者不并为一个术语；该术语是否已有更确切的表达归 [D-13](#d-13-术语使用前核对是否有更确切的表达)
  - **判定边界**: 代码、命令、路径与第三方 API 名称按原样书写，不由本条判定

## D-18 面向使用者的正文陈述可用之处，不陈述内部身份

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 面向使用者说明某对象用途的正文表述
- **动作**: 把该表述写成读者能用该对象做什么、何时选用、主要代价是什么
- **产出物**: 承载该说明的正文表述
  - **形态**: 叙述的落点是读者的可观察结果，不叙述该对象的内部角色、注册项或组件构成；读者会在配置、命令或公开接口中直接使用的标识符可写出，其余内部标识符从略
  - **判定口径**: 该表述可指认读者由此获得的能力或结果；不以内部函数、事件流或数据流为叙述主体
  - **语义判据**: 该表述陈述的是读者能用它做什么，还是它在实现里的身份——后者只在交代模块职责与归属的文档中才是正文要说的内容
  - **判定边界**: 以交代内部职责与归属为自身目的文档的正文，其叙述对象就是内部职责，不由本条判定；推导与辩护的取舍归 [D-06](#d-06-正文陈述契约不承载推导与辩护)

## D-19 操作性断言须以运行为证据

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 正文中关于命令、配置、默认值、报错、平台差异一类操作事实的断言
- **动作**: 在当前版本上原样运行该操作或以该配置装载，据观察结果写出该断言
- **产出物**: 承载该断言的正文表述
  - **形态**: 断言的内容以实际观察到的输出、警告与失败为准；依赖不可得的密钥或外部环境时，写出该限制并点名承担核实的一方，而不代为断言其行为
  - **判定口径**: 每处操作事实都能指认其依据为一次实际运行；正文不出现无法复现的内容；命令、字段、默认值与行为均非取自记忆、类比或相邻对象的说明
  - **语义判据**: 该断言是观察所得还是转述所得——复现失败时修正该断言，而非修正观察手段
  - **判定边界**: 由设计导出的常量与取舍结论不属操作事实；数值估计的归属与边界归 [D-07](#d-07-不确定表述必须有归属或边界)

## D-20 正文陈述须落在其应有的层级

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 同一事实可能落在多个层级的文档中
- **动作**: 把该事实写在离它最近的归属层级——局部约定留在使用它的那份文档，跨对象内容按读者群与学习意图归入对应层级
- **产出物**: 承载该事实的文档及其位置
  - **形态**: 该事实的承载层级与它的适用范围一致；局部约束不上升到全局文档，全局内容不散落在某一局部文档
  - **判定口径**: 逐处事实比对其承载文档的适用范围，二者一致
  - **语义判据**: 该事实的读者是谁、范围有多大——据此判断它应落在哪一层级；省略实现细节与罕见情形，除非它们改变需维护的约定
  - **判定边界**: 该事实是否改变契约归 [D-06](#d-06-正文陈述契约不承载推导与辩护)；它是否属可自行取回的事实归 [D-02](#d-02-正文不转述可自行取回的事实)；本次是否移动既有文档不属本条判定

## D-21 正文段落保持一个物理行

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 正文中的段落
- **动作**: 把每个段落写成不换行的单个物理行，不按显示宽度硬折行
- **产出物**: 段落文本
  - **形态**: 一个段落在源文件中占一个物理行；换行只用于分隔真正的块结构
  - **判定口径**: 段落内不出现仅由显示宽度导致的物理换行；折行的权威归渲染端，源文件只承载结构
  - **语义判据**: 该处换行是结构分隔还是为排版而折断——同一段落在源码视图与预览视图下若读法不同，即判为硬折行
  - **判定边界**: 列表项、代码围栏、表格、引用块、空行分隔的块与标题正文均属真正的块结构，不由本条判定

## D-22 决策记录须承载反论、代价与可观察验收面

- **when**: 撰写、修订或审阅决策记录类文档的正文
- **scope**: 决策记录、提案及其同类的结论性文档
- **动作**: 在该文档中写出反对该取舍的最强论据、所放弃的能力，以及该取舍为何仍然成立
- **产出物**: 该文档的结论性表述
  - **形态**: 最强反论可被读者完整读出；放弃的能力与其重新引入的条件写明；取舍成立的理由成句；验收面为可观察的最终状态而非主观的完成断言
  - **判定口径**: 文档中存在最强反论、放弃的能力与可观察验收面三者的对应表述
  - **语义判据**: 反论是否取最强的那一版而非稻草人；验收面是否可被外部观察者判定
  - **判定边界**: 普通正文不得承载辩护，其取舍归 [D-06](#d-06-正文陈述契约不承载推导与辩护)，本条只适用于决策记录这一体裁；文档的历史阶段叙述归 [D-04](#d-04-正文陈述当前状态不叙述变更)

## D-23 面向使用者的说明须承载消费方约定

- **when**: 撰写、修订或审阅面向使用者的说明类文档的正文
- **scope**: 面向使用者交代某对象用法与约束的文档，其体裁取其通用名而不绑定具体产物形态
- **动作**: 在该文档中写出消费方需要的约定
- **产出物**: 该文档的约定性表述
  - **形态**: 配置方式、语义、失败情形、限制与边界、扩展点、对使用者的可观察影响，凡存在者均写出；他方拥有的文本以引用给出；长期存在的缺口与维护者易陷的陷阱保留，日常待办不入此列
  - **判定口径**: 上述若干项凡存在者均有对应表述；不逐字段复述他处已载的成员清单
  - **语义判据**: 该表述是否影响使用或安全维护——影响者保留，不影响者不属本条的约定；该文档是否被当作待办积压处
  - **判定边界**: 操作步骤与验证方式的完备性归 [D-24](#d-24-操作手册须含前置条件与可观察验证)；可自行取回的事实归 [D-02](#d-02-正文不转述可自行取回的事实)

## D-24 操作手册须含前置条件与可观察验证

- **when**: 撰写、修订或审阅操作手册类文档的正文
- **scope**: 指导读者完成某项操作的文档
- **动作**: 在该文档中写出前置条件、必需操作、真实入口路径、可观察的验证方式与简明警告
- **产出物**: 该文档的操作性表述
  - **形态**: 读者可据文档给出的可观察验证自行判断操作是否成功；入口路径为真实可走通的路径而非示意
  - **判定口径**: 前置条件、必需操作、入口路径、可观察验证四项齐备；验证方式给出的是外部可观察的结果，而非叙述者自己的断言
  - **语义判据**: 读者能否据可观察验证自行判定成败
  - **判定边界**: 该文档是否被当作待办积压处归 [D-23](#d-23-面向使用者的说明须承载消费方约定)；操作事实的证据要求归 [D-19](#d-19-操作性断言须以运行为证据)

## D-25 正文以 Markdown 语法撰写

- **when**: 撰写、修订或审阅知识库与指令类文档的正文
- **scope**: 正文所取的标记语法
- **动作**: 用 Markdown 原生语法承载正文的全部结构，把以其它标记语法承载的表述改写为等价的 Markdown 结构
- **产出物**: 承载正文的文档及其结构标记
  - **形态**: 标题、段落、列表、表格、围栏代码块、引用、强调与链接各自取 Markdown 原生记号，正文内不出现 HTML 标签
  - **判定口径**: 逐行解析文档，凡围栏代码块与行内代码之外出现 HTML 标签（匹配 `</?[A-Za-z][A-Za-z0-9-]*(?:\s[^<>]*)?/?>`）者，逐处点名其行号与该标签
  - **语义判据**: 某处结构在渲染端是否有 Markdown 原生等价物——有则须改用该等价物，无则改写为既有原语的组合，仍不可表达时中止并点名该结构
  - **判定边界**: 围栏代码块与行内代码内的 HTML 属被讨论、被示例或被测试的对象，不由本条判定；渲染端对 HTML 的处置策略与实现不由本条判定；非 Markdown 载体的产物（`LICENSE`、JSON、源码文件）不由本条判定；除 HTML 标签外的结构记号是否属 Markdown 原生记号由语义判据判定，本条不另给机械口径
