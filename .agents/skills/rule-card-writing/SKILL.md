# 规则卡片与规范册撰写工序

本 skill 的工序由一条约束链推出：判定只能读若干字段，故凡要生效的语义都必须落在这些字段里，而字段的合法集合是封闭登记的。执行时自上而下走。

## 判据源

本 skill 的按条判据以全文唯一权威源为准：[规则卡片与规范册撰写规范](reference/rule-card-writing-constraints.md)——随本 skill 分发，本 skill 不复制其条款。本 skill 工序中的 `§n` 与 `F-nn` 即该册的章节与条目编号。行文另受工程级 SKILL [文档撰写 SKILL](../doc-writing/SKILL.md) 约束，其判据源为 [文档撰写规范](../doc-writing/reference/doc-writing-constraints.md)；单独分发本 skill 时以同名 skill 为准。

## 工序

1. **定判定输入**：先写出生效条件、强度、行为、完成判据四者的取值，再落笔成字段。标题、层标签、注释与一切结构标签不参与判定，写在其中的限制不具约束力。
2. **查登记**：顶层字段查规范 §0.1，子标签查 §0.2，文档层定义项查 §0.3；覆盖点与缺口的落点取规范 §5／§6 的登记，不在卡片里另立。
3. **填必填核心**：`id`、`when`／`scope`、`action`、`artifact`；`id` 的前缀取规范 F-01 的登记表，缺登记先补。
4. **逐字段撰写**：按规范 §2 的 F-01 至 F-17；`scope` 与 `action` 先选 `form`，再写该形态专属字段，非当前形态的字段不出现。
5. **拆判定维度**：`artifact` 的可机械求值部分写 `判定口径`，不可机械求值部分写 `语义判据`，不判定的对象写 `判定边界` 并点名承担者。
6. **收尾**：条件不成立的行整行删除；按规范 §3 自查引用完整性与计数上限。
7. **组册**：册正文只由承载标题行与并列卡片构成；新条目按规范 §5 的 S-01 至 S-04 走准入、取用范围、落笔次序与缺口登记。
8. **核验**：以规范 §1 的模板与被撰文档既有卡片的字段行互为对照；有 lint、测试或生成流程时跑该文档自己的核验命令，本 skill 不另立判据。

## 高频改写

- 意图级表述、程度副词、工具与参数细节改写为工具无关的具体动作。
- 执行时序从适用性槽移入 `action`，并把 `ordered_steps` 限定在步间存在数据依赖时。
- 判别依据移入 `action`，格式依据留在 `artifact`，两者不互串。
- 字段值内自造的分隔记号改写为具名子标签。
- 本地可判定的例外改写为 `scope` 的原子谓词取反，不写成 `外部例外`。
- 覆盖只写正向指针，被覆盖方内嵌 `覆盖点`。

## 自检

- 每个字段名与子标签名都能在规范 §0.1／§0.2 解析到。
- `id` 落在已登记前缀内，且全域唯一。
- 必填核心齐备；「判定口径」与「语义判据」至少出现其一。
- 完成判据写在 `artifact` 内，未在 `动作` 值或 `产出物` 值里自造分隔记号。
- 册正文内无非卡片块，条目之间不插其它标题级别。
- 「必须／不得／should」不出现在 `why:nb` 内。
