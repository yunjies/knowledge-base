# 规范册撰写工序

本 skill 的工序由一条约束链推出：册层的判定分两路——**块集合与排列**（册正文由哪些块构成、卡片以什么先后排列）与**准入与登记**（新条目的字段名可否解析、缺口是否给出处置方式）；故凡要生效的册层语义都必须落在条目卡片本身、它们在册内的先后，或册层登记块上。执行时自上而下走。

## 判据源与范围

本 skill 的按条判据以全文唯一权威源为准：[规范册撰写规范](reference/spec-book-writing-constraints.md)——随本 skill 分发，本 skill 不复制其条款。本 skill 工序中的 `§n` 与 `S-nn` 即该册的章节与条目编号；工序中指向卡片层构件的编号一律带限定词"卡片层"。

本 skill 管**册层构成**。**单条规则卡片的字段结构**归[规则卡片撰写工序](../rule-card-writing/SKILL.md)，其判据源为[规则卡片撰写规范](../rule-card-writing/reference/rule-card-writing-constraints.md)；写卡片本体时取它，本 skill 只在落笔位置与册内取舍上编排次序。落在卡片字段行与册正文里的文本，其**行文表述**取[文档撰写 SKILL](../doc-writing/SKILL.md)——含字段值、子标签行与列表的写法。**执行者不得越过判据源另立判据**：本 skill 只编排落笔次序，工序中不新增判据；册层规范未覆盖且册层 `§0.1`（缺口登记）亦未登记的情形，须显式报出该情形与其归属，不得就地发明写法、不得把既有断言改写成"通常""建议"一类措辞来放行。

## 工序

1. **判成册**：核对本册两条同时成立——册内条目是"一条规则一张卡片"且其 ID 前缀在**本册内**一致；册有承载它的标题行——独立成册即 H1，作为章节即该章节标题行（`S-00` 的 ①②）。两者缺一即不构成本册，不套用本册其余各步。
2. **立承载标题行，划出登记区**：先写承载标题行；其**之前**设登记区，用以承载卡片层 §0.3 登记的文档层定义项（如模态词面对照表）与**本册的册级登记块**（规范 [§0.1](reference/spec-book-writing-constraints.md#01-缺口登记) 的缺口登记）——该区不属册正文、不受"只由卡片构成"约束。承载标题行**之后**即为册正文，自该行起算。
3. **落笔条目**：一个条目一个章节，直接接在承载标题行之后，条目之间**依次并列、无分组**，全部条目取**同一标题级别**（级别由本册的层级结构给定，规则取卡片层 §1）。每条卡片的字段与子标签按[规则卡片撰写工序](../rule-card-writing/SKILL.md)写——本 skill 不重复其工序。
4. **准入登记**：条目拟用的字段名或子标签名，逐个核对是否已在卡片层 §0.1／§0.2 的登记处；未登记者先在**该登记处**补登记其标签、基数、必填性与取值约束，再落笔（`S-01` ①②）。**前缀不设登记**：本册用什么前缀由条目标题行本身给出，**本册内**一致即可。
5. **取用范围不落进册正文**：这里的"行"指**字段行与子标签行**（不是物理行）——用得上的行写出，用不上的行**整行不出现**，把取舍交回字段自身的缺省语义与触发条件；**不设册级取用范围声明段**（`S-02`）。若某个字段或子标签的取舍确实无法由条目文本与缺省语义推出，其承载点在册正文**之外**。
6. **定次序**：某条的落笔位置无法由它自身（`形态`／`判定口径`／`判定边界` 或 `动作` 步骤次序）取回、只能由他条反推时，按条目产出物之间的依赖关系排定先后，**以卡片在册内的物理先后承载**，被依赖者在前；**不另立次序表**（`S-03`）。
7. **登记缺口**：落在本册覆盖范围内而册内条目都判不了的情形，登记为缺口并写明**遇到时的处置方式**；**落点在册正文之外**（本手册的登记处即规范 §0.1，位于承载标题行之前）。情形闭合或前提不成立时，把该条从登记处**移除**——登记处只列当前开放的缺口（`S-04`）。
8. **核验**：册正文自承载标题行起逐行解析，凡不能解析为卡片构件的非空行即多余块，逐处点名其行号与文本；条目之间不得插入其它标题级别（`S-00` 判定口径）。卡片内部的字段与子标签的正确性取回卡片层 §2，不由本步判定。有 lint、测试或生成流程时跑该文档自己的核验命令。

## 高频改写

- 册首出现声明段、分组标题、缺口章节、附录或分隔线，改为删除——册正文自承载标题行起只由并列卡片构成，册级登记块移到承载标题行之前的登记区。
- 册正文内出现"本册取用／不出现下列字段"一类的册级声明，改为删除该声明、把取舍落到各条目文本里。
- 另立了条目次序表或次序清单，改为删除表、只调卡片在册内的物理先后。
- 承载标题行之后插入了非卡片块，改为把它移入承载标题行**之前**的登记区，或删除。
- 新增条目用了一个未登名字段的字段名或子标签名，改为先在卡片层 §0.1／§0.2 登记再落笔。
- 册内条目各自取不同标题级别，改为全文取同一级别。
- 缺口条目只描述问题，改为补齐"遇到时的处置方式"；已闭合的缺口，改为从 §0.1 移除。

## 自检

**本清单是高频错项摘要，不是判据全集**；逐条判据以 `reference/` 规范各条自身的判定口径与语义判据为准。

- 承载标题行之后至册末，无任何非卡片块；条目之间不插其它标题级别。
- 册内全部条目取同一标题级别。
- 条目 ID 前缀在**本册内**一致（判域是本册，不是整篇文档），且各 ID 在本册内唯一。
- 册正文内不出现册级取用范围声明段；不出现次序表。
- 新增或修订的条目所用的字段名与子标签名都能在卡片层 §0.1／§0.2 解析到，且新登记项不与既有登记重名（`S-01`）。
- 存在依赖关系的条目对，被依赖者所在行号小于依赖者所在行号（`S-03`）。
- 缺口登记不在册正文内，且每条都给出处置方式；已闭合的已移除。
