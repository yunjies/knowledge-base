# 规范册撰写规范

> **范围**：本文管**规范册怎么组**，逐条见 [§1 册层规则](#1-册层规则)。**单条规则卡片怎么落笔**不由本文规定，取[规则卡片撰写规范](../../rule-card-writing/reference/rule-card-writing-constraints.md)（下称**卡片层规范**）。
> **判据源**：本文的按条判据以本文自身为唯一权威源，不复制卡片层规范的条款；判据不依赖读者推断，其求值口径取卡片层 [§0.5](../../rule-card-writing/reference/rule-card-writing-constraints.md#05-判定真值源越界即失效)。规范未覆盖的情形，撰写者显式报出该情形与其归属、交回使用者，不就地发明写法，也不写进册内。
> **角色**：本文的四类角色——**撰写者**、**解析器**、**判定者**、**执行环境层**——及其彼此分离的约束，取卡片层规范的[角色声明](../../rule-card-writing/reference/rule-card-writing-constraints.md#规则卡片撰写规范)；四者是角色，不指向任何具体工具、模型或组织。

## 1. 册层规则

### S-00 册正文只由并列的规则卡片构成

- **scope**: 显式布尔组合
  - ① 该**册**以规则卡片承载某类约束——即其条目是"一条规则一张卡片"，条目 ID 取该册所用的前缀，前缀在**该册内**一致（判域是该册自身，不是整篇文档；前缀的形态与编号空间取卡片层 [F-01](../../rule-card-writing/reference/rule-card-writing-constraints.md#f-01-id--规则标识)，而"前缀须一致"这一条件由本条自身承载）
  - ② 该册有**承载它的标题行**——独立成册时即文档的 H1 标题行，作为章节时即该章节的标题行；**判定次序与优先序**：先取该册条目集合所在的标题层级，承载标题行即全部条目标题行的**直接父标题行**——文档同时具备 H1 与承载条目的分组标题时，以**承载条目集合的那一层标题**为承载标题行，取 H1 者次之。本文自身的承载标题行为 `## 1. 册层规则`
  - **连接**: ① and ②
- **动作**: 把册正文写成若干并列的规则卡片，一个条目一个章节
- **产出物**: 册正文
  - **形态**: 承载标题行之后**直接**是首个条目的标题行，条目之间**依次并列**、无分组。条目取**同一标题级别**，级别由文档层级结构给定（取回卡片层 [§1](../../rule-card-writing/reference/rule-card-writing-constraints.md#1-规则卡片模板) 的标题行级别规则）；条目以下为卡片自身的字段行与子标签行。**册正文自承载标题行起算**：该行之前可承载卡片层 [§0.3](../../rule-card-writing/reference/rule-card-writing-constraints.md#03-文档层定义的文本形态) 的文档层定义项（如模态词面对照表这类表格），其前的行不属册正文、不由本条判定，也不受"只由卡片构成"的约束。**承载标题行之后**，册正文除条目卡片外**不含任何其它内容块**——不设册首声明段、不设分组标题、不设附录、不设分隔线与引用块等一切非卡片块
  - **判定口径**: 逐行解析文档，凡**不能按字段全集的解析规则解析为卡片构件**的非空行（即非承载标题行、非条目标题行、非字段行、非子标签行、亦非字段值所允许的承载行），判为册正文的多余块，逐处列出其行号与文本；条目之间不得插入其它标题级别。**扫描自承载标题行起**，其前的行不在扫描范围内
  - **判定边界**: 卡片内部的字段与子标签的正确性不由本条判定，取回卡片层 [§2](../../rule-card-writing/reference/rule-card-writing-constraints.md#2-字段规则定义)；哪些行算卡片构件，由该册的解析规则给定，本条不复制其清单；条目内容承载什么不由本条判定。**卡片层的元规范**——其产物即卡片格式与共享登记本身（如卡片层规范 [§0](../../rule-card-writing/reference/rule-card-writing-constraints.md#0-记号与通则) 至 [§4](../../rule-card-writing/reference/rule-card-writing-constraints.md#4-禁止字段与禁止形态) 的字段全集与各登记表）——不承载规则卡片，按 [①](#s-00-册正文只由并列的规则卡片构成) 不落入本条，其登记块不由本条判定
  - **语义判据**: 册正文是否恰好由承载标题行与条目卡片构成——读者打开册子即进入条目本身，无须先读一段册级前言才能读到规则；判据锚在**解析单位**上：掺入无法解析为卡片的块后，读者与解析器对"该册有几条规则"没有统一答案
- **失败行为**: fail_loud
  - **行为**: 出现非卡片块时中止写入并逐处点名该块的行号与类型，不把它改写为卡片内的一行来迁就，也不以"读者需要入口"为由保留册首段落

### S-01 新条目准入

- **scope**: 显式布尔组合
  - ① 向既有规范册新增条目
  - ② 修订既有条目所取的字段与子标签
  - **连接**: ① or ②
- **动作**: 按序执行（步间有数据依赖）：
  - ① 取本条拟用的字段与子标签，逐个核对是否已在字段全集中登记
  - ② 有未登记者，先在字段全集（卡片层 [§0.1](../../rule-card-writing/reference/rule-card-writing-constraints.md#01-标签--字段对照) 与 [§0.2](../../rule-card-writing/reference/rule-card-writing-constraints.md#02-子标签登记封闭集合) 的登记处）登记其标签、基数、必填性与取值约束，再落笔
  - ③ 按 [S-02](#s-02-册级取用范围不落进册正文) 判定该册的取用范围：取舍直接体现在条目文本里，**不另设册级登记**
  - ④ 新条目改变条目间依赖时，按 [S-03](#s-03-条目按依赖次序落笔) 判定该依赖是否触发落笔次序，触发则更新之
- **产出物**: 准入结果
  - **形态**: 新条目本身；未登记名称在字段全集中的新增登记项；取用范围按 [S-02](#s-02-册级取用范围不落进册正文) 落在条目文本里而不另立登记；依赖触发 [S-03](#s-03-条目按依赖次序落笔) 时一并调整条目在册内的先后
  - **判定口径**: 新条目使用的每个字段名与子标签名都能在字段全集中解析到；新增登记项的标签名不与既有登记重名
  - **语义判据**: 新引入的名称是否承载了既有名称无法承载的语义——与既有名称同义者不新立，改用既有名称
  - **判定边界**: 新条目判据内容本身的成立与否不由本条判定，由该条自己的产出物判定

### S-02 册级取用范围不落进册正文

- **scope**: 某个规范册的取用范围
- **动作**: 不为该册另写取用范围声明，把各行的取舍交回**字段自身的缺省语义与触发条件**裁决
- **产出物**: 册对各行的取舍
  - **形态**: 取舍结果直接体现在条目文本里——用得上的行写出，用不上的行整行不出现；该行不出现即表示其触发条件在该册不成立，读者据该字段的缺省语义（取回卡片层 [§0.3](../../rule-card-writing/reference/rule-card-writing-constraints.md#03-文档层定义的文本形态) 与 [§2](../../rule-card-writing/reference/rule-card-writing-constraints.md#2-字段规则定义)）即可裁决，**不另设册级声明段**
  - **判定口径**: 册正文内不出现对字段取用范围的册级声明——即没有哪一行以"该册取用/不出现下列字段"为内容的非卡片块；某行是否该出现，逐个字段按其触发条件与该册条目文本判定
  - **语义判据**: 该册的取用范围是否真的无法由条目文本与字段缺省语义推出——可推出者不另立声明，声明一份即造出与该缺省语义并行的第二事实源；**取舍恒由条目文本承载**（依据字段自身的缺省语义与触发条件），推不出的情形不另设外部承载点
  - **判定边界**: 字段自身的语义、基数的正确性不由本条判定，取回卡片层 [§2](../../rule-card-writing/reference/rule-card-writing-constraints.md#2-字段规则定义)；某个字段按全集规定是否条件必填，也不由本条判定；本条不判定册正文的块集合，册正文的构成归 [S-00](#s-00-册正文只由并列的规则卡片构成)

### S-03 条目按依赖次序落笔

- **scope**: 规范册内的条目集合，且其中存在**落笔位置无法由该条自身取回**的条目——即某条的位置不由它自己的 `形态`／`判定口径`／`判定边界`，也不由它 `动作` 的步骤次序给定，只能由他条反推
- **动作**: 按条目产出物之间的依赖关系确定落笔次序，并**以卡片在册内的物理先后**承载该次序
- **产出物**: 落笔次序
  - **形态**: 卡片在册内的排列次序本身即该次序——被依赖者的卡片排在依赖者的卡片之前。**不另立次序表**：次序表是同一事实的第二处承载，与卡片排列分叉时无从裁决哪一处为准，且它本身即册正文的多余块（见 [S-00](#s-00-册正文只由并列的规则卡片构成)）
  - **判定口径**: 逐个取出存在依赖关系的条目对，被依赖者所在行号小于依赖者所在行号
  - **判定边界**: 次序不是流水线禁令——实际撰写可以迭代，本条只判定卡片排列是否满足偏序；某条的落笔位置已由该条自身的 `形态`／`判定口径`／`判定边界` 或 `动作` 的步骤次序给定时，该依赖不触发本条，不为该条另设约束
