# 流程类文档撰写规范

## P-00 管辖范围按产出物划分

- **scope**: 判定某文档是否落在本册管辖范围之内
- **动作**: 按该文档的产出物类型判定其是否为本册所称的流程类文档
- **产出物**: 流程类文档的判定
  - **形态**: 判定结论，及其所依据的产出物类型
  - **判定口径**: 该文档以流程图及其配套说明承载内容——其正文由一张或多张流程图，以及各节点的详述章节构成
  - **语义判据**: 判定是否按**产出物**作出而非按**任务名**作出——把非标准描述改写为流程类文档、审阅流程类文档并出具结论，这两个任务的方法与结论格式不属本册，但二者的产出物仍落在流程类文档之列，其图与节点结构依本册判定
  - **判定边界**: 正文的行文表述不由本册判定，归 [文档撰写规范](../../doc-writing/reference/doc-writing-constraints.md)；审核结论的准则不由本册判定，归 [根 AGENTS.md](../../../../AGENTS.md) 的「决策与审核准则」

## P-01 H1 之后以自然段陈述本图的核心目标

- **scope**: 同时满足：
  - ① 文档为流程类文档
  - ② 该文档存在 H1 标题行
- **动作**: 在 H1 之后的首个内容块陈述本图的核心目标
- **产出物**: H1 之后的首个内容块
  - **形态**: 自然段落；标题已完整给出目标时改述本图的范围与产出（从哪开始、到哪结束），不复述标题
  - **判定口径**: 该块与 H1 之间除空行外无其它内容块；该块的块类型为段落，即无列表标记、无代码围栏、无 mermaid 围栏、无表格分隔行、无引用标记
  - **语义判据**: 该段是否陈述本图核心目标；文档含多张流程图时，每张图各自适用本条
  - **判定边界**: 该段之后的内容块及其次序不由本条判定
- **失败行为**: fail_loud
  - **行为**: 首块不是自然段落时停止撰写并指出该块的块类型，不把目标移入图内节点或以图后段落补救

## P-02 首个 h2 只承载主流程图

- **scope**: 流程类文档的第一个 h2 章节
- **动作**: 在首个 h2 章节内绘制主流程图
- **产出物**: 首个 h2 章节
  - **形态**: 其正文仅含一张 mermaid 主流程图；主图只画主干，子流程的内部步骤不内联；子流程在其触发节点的章节内绘制，见 [P-08](#p-08-子流程蓝图型节点在本章内先绘其图再递归成章)；与子流程对应的位置保留其入口节点，主图连线经过它，被移出本图的是子流程的内部步骤而非它在流程中的位置
  - **判定口径**: 该章节内 mermaid 围栏恰为一个；除该围栏外该章节不含其它内容块
  - **语义判据**: 某节点的内部步骤是否须另起一张图方能讲清——是则其内容属子流程，留在本图内即违规
  - **判定边界**: 单图文档不因缺少后续子流程章节而违规
- **失败行为**: fail_loud
  - **行为**: 出现须另起一张图方能讲清的节点时停止内联，改为在该节点取子流程蓝图型并按 [P-08](#p-08-子流程蓝图型节点在本章内先绘其图再递归成章) 展开

## P-03 节点分标识符与描述名两槽，描述名同图内不得重名

- **scope**: 流程图内的每个节点
- **动作**: 为节点写标识符与描述名两槽
- **产出物**: 图内节点标注
  - **形态**: 书写形态为 `ID["描述名"]`；标识符为标准化英文短码，只承担图内引用与机器阅读；描述名为面向读者的自然语言，可用中文，不承担引用职责
  - **判定口径**: 每个节点有且仅有一个标识符槽与一个描述名槽；同一张图内描述名互不重复，即逐节点取描述名计数，任一计数大于一即违规，唯一性以单张图为范围，跨图重名不作违规；标识符匹配 `^[A-Z][A-Z0-9_]*$`；每条边的端点标识符都存在于本图节点集合中，改名后不留下指向旧名的边
  - **语义判据**: 标识符脱离本图其余部分能否判断该节点的作用（本条正则只判形态，不判表意强度；形态合规而表意不足者按失败行为处置）
- **失败行为**: fail_loud
  - **行为**: 改标识符后有边指向不存在的端点时报错中止，不保留悬空引用；标识符形态合规但脱离本图其余部分无法判断节点作用时，改写到可判断为止，不以形态合规为由放行

## P-04 节点按角色分型，同型取固定形状

- **scope**: 流程图内的每个节点
- **动作**: 按节点在本图中的角色为它选择形状
- **产出物**: 节点形状
  - **形态**: 开始与结束型取 `(["..."])`，条件型取 `{"..."}`，功能逻辑型取 `["..."]`，子流程蓝图型取 `[["..."]]`；形状的可取集合以渲染管线实际支持的 mermaid 原生形状为限，不自造形状、不改渲染器
  - **判定口径**: 每个节点的形状属于上述四种之一，且为该管线可渲染的 mermaid 原生形状；同一角色的节点在本图内取同一形状；角色由图中的分叉行为决定，即出边有两条及以上或带条件标签的节点归条件型，节点文本里出现判断类字样不改变其角色，颜色与样式不参与角色判定
- **依赖**: MERMAID@11
  - **权威源**: mermaid 官方形状语法
  - **降级行为**: 不可解析时中止撰写并上报不可解析的术语与版本，不猜测形状集
- **失败行为**: fail_loud
  - **行为**: MERMAID@11 不可解析时中止撰写并上报不可解析的术语与版本，不猜测形状集；出现本册已列四种之外的角色时拒绝落笔，先为该角色指定形状并登记进本册，再继续撰写

## P-05 允许成环，但每个节点都须可达完成节点

- **scope**: 单张流程图内的每个节点；含环的图与不含环的图同等适用
- **动作**: 对每个节点沿出边做可达性遍历，判定其能否命中结束型节点
- **产出物**: 可达性判定
  - **形态**: 每个节点至少一条沿有向边通向结束型节点的路径；无出边的非结束型节点列为违规点
  - **判定口径**: 对每个节点沿出边遍历，命中结束型节点的路径数至少为一；环的存在本身不计为违规，被判违规的是无出口的环
  - **判定边界**: 从开始节点到各节点的可达性不由本条判定；结束型节点的角色与形状判定归 [P-04](#p-04-节点按角色分型同型取固定形状)；主流程图与各子流程图之间的连接不由本条判定（该连接由 [P-02](#p-02-首个-h2-只承载主流程图) 的入口节点承担，归 [P-08](#p-08-子流程蓝图型节点在本章内先绘其图再递归成章) 递归适用）
- **失败行为**: fail_loud
  - **行为**: 出现只能回到环内、无法流向完成节点的节点时判定该图违规，并逐一点名这些节点

## P-06 主流程图之后逐节点成章，以自然语言详述其逻辑

- **scope**: 主流程图的每个节点；子流程蓝图型节点除外，其展开见 [P-08](#p-08-子流程蓝图型节点在本章内先绘其图再递归成章)
- **动作**: 以自然语言为主流程图的每个节点各写一个章节，详述该节点的逻辑
- **产出物**: 节点详述章节
  - **形态**: 章节标题取该节点的标识符，标题级别与主流程图章节并列（h2；嵌套时随层级加深）；正文以自然语言描述该节点做什么与在什么条件下走哪条出边
  - **判定口径**: 主流程图每个节点标识符在后续章节标题中出现且仅出现一次，即一一对应、不重不漏；章节正文不含 mermaid 围栏；环内节点同等适用；节点改名后其章节标题随之更名
  - **语义判据**: 只读该章节能否说出该节点做什么与在什么条件下走哪条出边，无须回看主图。其中"在什么条件下走哪条出边"指**该条件的判定语义**——图内标签只有一个词面，判定语义是本章节的净增量；**出边的存在与指向是结构事实，权威在主图，本节不复述**——复述图内已载的结构只会造出第二事实源，且它随主图改动而静默失配
  - **判定边界**: 图内的节点与边本身不由本条判定；本章节与主图的一致性由主图承担
- **失败行为**: fail_loud
  - **行为**: 某节点找不到唯一对应章节时列出缺失与重复的标识符，不以概览章节充当替代；正文复述图内已载的出边存在与指向时改为只写条件的判定语义

## P-07 输入参数与输出参数按固定槽位标准化描述

- **scope**: 节点详述章节
- **动作**: 在该章节内列出节点的输入参数与输出参数
- **产出物**: 节点章节的输入栏与输出栏
  - **形态**: 两栏齐备；每项形如 `` - `参数名`：类型描述；来源为 X `` 或 `` - `参数名`：类型描述；去向为 X ``，其中 X 取上游或下游节点的标识符，参数来自流程之外时取该外部来源的名目；无参数时该栏显式写「无」；类型描述为自由文本，按该参数的实际语义写，同一参数在多处的类型描述须一致
  - **判定口径**: 输入栏与输出栏同时存在，任一栏不得省略；同一参数在全文档内只有一个名字，上游节点的输出与下游节点的输入按名字对齐；参数名匹配 `^[A-Z][A-Z0-9_]*$`，且不与任何节点标识符重名
  - **判定边界**: 本条只约束详述章节内的参数描述，图内节点的描述名不由本条判定
- **失败行为**: fail_loud
  - **行为**: 某栏缺失时判违规并指出缺的是哪一栏，不以「无参数」为由整栏省略

## P-08 子流程蓝图型节点在本章内先绘其图，再递归成章

- **scope**: 角色为子流程蓝图型的节点所在章节
- **动作**: 按序执行（步间有数据依赖）
  - ① 在该章节内绘制本节点的子流程图
  - ② 以该子流程图为输入，按本册同一套规则为其每个节点写标准化章节
- **产出物**: 子流程图与其节点章节
  - **形态**: 子流程图在该章节内先于其节点章节出现，且由其自身承载、不占用文档别处的章节；章节层级随嵌套加深一级；[P-01](#p-01-h1-之后以自然段陈述本图的核心目标) 至 [P-07](#p-07-输入参数与输出参数按固定槽位标准化描述)、[P-11](#p-11-图以-mermaid-围栏承载) 全部适用于该子流程图及其节点章节
  - **判定口径**: 该章节内子流程图的围栏位置早于其首个节点章节标题；对本子流程图重复 [P-06](#p-06-主流程图之后逐节点成章以自然语言详述其逻辑) 的覆盖判据，其每个节点在更深一层出现且仅出现一次；展开到某层不再含子流程蓝图型节点时该分支递归结束，本册不设深度上限
  - **语义判据**: 子流程图内某节点的内部步骤是否仍须另起一张图方能讲清（是则继续递归，判据同 [P-02](#p-02-首个-h2-只承载主流程图)）
- **失败行为**: fail_loud
  - **行为**: 子流程图出现在其节点章节之后时判违规并指出实际次序，不靠调整节点章节位置迁就

## P-09 文档以 H1 标题行开头

- **scope**: 流程类文档
- **动作**: 在第一行写一个 H1 标题行
- **产出物**: 文档的 H1 标题行
  - **形态**: 首行形如 `# <标题>`；标题为面向读者的自然语言，概括本流程的起止与产出
  - **判定口径**: 文档第一行匹配 `^# \S`；全文层级为 H1 的行恰有一行
  - **语义判据**: 标题是否概括本流程的起止与产出，而非只写流程名或只写其中一段
  - **判定边界**: H1 与首个内容块之间的次序与形态归 [P-01](#p-01-h1-之后以自然段陈述本图的核心目标)；标题的措辞质量不由本条判定
- **失败行为**: fail_loud
  - **行为**: 首行不是 H1 时停止撰写并要求补齐 H1，不靠提升某个 h2 的级别来迁就，也不在无 H1 的状态下继续落笔

## P-10 主流程图落在首个 h2 章节

- **scope**: 流程类文档
- **动作**: 为承载主流程图建立首个 h2 章节
- **产出物**: 文档的首个 h2 章节
  - **形态**: H1 与首个 h2 之间除 [P-01](#p-01-h1-之后以自然段陈述本图的核心目标) 所要求的自然段落外无其它内容块；该 h2 的章节标题为面向读者的自然语言
  - **判定口径**: 文档存在 h2 标题行，且首个 h2 之前的内容块至多一个；首个 h2 之前不得出现 h3 及更深层级标题
  - **语义判据**: 该 h2 的标题是否表明它承载的是主干而非某个子流程
  - **判定边界**: 首个 h2 章节内部承载什么归 [P-02](#p-02-首个-h2-只承载主流程图)；后续章节的标题级别归 [P-06](#p-06-主流程图之后逐节点成章以自然语言详述其逻辑)
- **失败行为**: fail_loud
  - **行为**: 文档无 h2 标题行时停止撰写并要求补建承载主流程图的首个 h2，不以 h1 之外的任意内容承载主图

## P-11 图以 mermaid 围栏承载

- **scope**: 流程图围栏；主流程图与各子流程图同等适用
- **动作**: 以 mermaid 围栏承载每张流程图
- **产出物**: 流程图围栏
  - **形态**: 图只能存在于信息串为 `mermaid` 的围栏内；非图内容的围栏信息串取该内容的语言标识（如 `bash`），不得取 `mermaid`
  - **判定口径**: 每张流程图所在围栏的起始行匹配 `^\s*```mermaid\s*$`；节点章节内除 [P-08](#p-08-子流程蓝图型节点在本章内先绘其图再递归成章) 所允许的子流程图围栏外，不出现信息串为 `mermaid` 的围栏
  - **语义判据**: 该围栏内容是否为本册意义上的流程图（有向、含节点与边），而非时序图、类图等其它 mermaid 图种
  - **判定边界**: 围栏内的节点形状与可达性归 [P-04](#p-04-节点按角色分型同型取固定形状) 与 [P-05](#p-05-允许成环但每个节点都须可达完成节点)；围栏的**数量与位置**归 [P-02](#p-02-首个-h2-只承载主流程图) 与 [P-08](#p-08-子流程蓝图型节点在本章内先绘其图再递归成章)
- **失败行为**: fail_loud
  - **行为**: 出现非 mermaid 围栏承载的流程图时停止撰写并要求改写为 mermaid 围栏，不改渲染器、不把非 mermaid 图按等价算作合规；信息串缺失时补齐为 `mermaid`
- **依赖**: MERMAID@11
  - **权威源**: mermaid 官方流程图语法
  - **降级行为**: mermaid 语法不可解析时中止撰写并上报不可解析的图种与版本，不猜测图种
