# 流程类文档撰写工序

本 skill 的工序由一条约束链推出：本册的判定只读「适用条件 → 承载动作 → 产出物」三段，故凡要生效的语义都必须落在产出物的子标签里，写在标题、注释或结构标记中的限制不具约束力。流程类文档的骨架由「H1 → 目标段 → 主图 → 逐节点章节」的落笔次序决定，故工序按该次序排列：先认体裁与立骨架，再画主图，最后逐节点展开并递归。执行时自上而下走。

## 判据源

本 skill 的按条判据以全文唯一权威源为准：[流程类文档撰写规范](reference/process-doc-writing-constraints.md)——随本 skill 分发，本 skill 不复制其条款。本 skill 工序中的 `P-nn` 即该册的条目编号。行文另受工程级 SKILL [文档撰写 SKILL](../doc-writing/SKILL.md) 约束，其判据源为 [文档撰写规范](../doc-writing/reference/doc-writing-constraints.md)；单独分发本 skill 时以同名 skill 为准。

## 工序

1. **判体裁**：按拟写文档的**产出物**判定它是否落在本册管辖——正文由一张或多张流程图及其各节点详述章节构成者即是（`P-00`）；判定不按任务名作出，故把流程描述改写为流程类文档、审阅流程类文档并出具结论这两个任务的方法与结论格式不属本册，但二者的产出物仍依本册判定其图与节点结构。
2. **立标题**：在第一行写一个 H1 标题行，标题概括本流程的起止与产出（`P-09`）。
3. **写目标段**：紧随 H1 写首个内容块，取自然段落，陈述本图的核心目标；标题已完整给出目标时改述本图的范围与产出（从哪开始、到哪结束），不复述标题（`P-01`）。
4. **开主图章节**：建立首个 h2 章节承载主干，标题表明它承载的是主干而非某个子流程；H1 与该 h2 之间除目标段外无其它内容块，也不得出现 h3 及更深层级标题（`P-10`）。
5. **画主图**：该章节内只画一张主流程图，以信息串为 `mermaid` 的围栏承载；主图只画主干，节点的内部步骤不内联，改按 `P-08` 在其触发节点处展开为子流程蓝图型节点，主图连线经过它（`P-02`、`P-11`）。
6. **规范节点**：每个节点写标识符与描述名两槽，形态为 `ID["描述名"]`——标识符为标准化英文短码且匹配 `^[A-Z][A-Z0-9_]*$`，描述名为面向读者的自然语言；同一张图内描述名互不重复，每条边的端点都指向本图已存在的节点，改名后不留悬空引用（`P-03`）。
7. **定形状**：按节点在本图中的角色取形状——开始与结束型取 `(["..."])`，条件型取 `{"..."}`，功能逻辑型取 `["..."]`，子流程蓝图型取 `[["..."]]`；角色由分叉行为决定（出边两条及以上或带条件标签者归条件型），颜色与样式不参与判定（`P-04`）。
8. **验可达**：对每个节点沿出边做可达性遍历，确认它至少有一条路径通向结束型节点；环本身不算违规，被判违规的是无出口的环，逐一点名这些节点（`P-05`）。
9. **逐节点成章**：为主流程图每个节点（子流程蓝图型除外）各写一个章节，标题取该节点标识符且与主图章节并列（嵌套时随层级加深），正文以自然语言写出该节点做什么与在什么条件下走哪条出边；"走哪条出边"只写该条件的判定语义，不复述边的存在与指向——那是主图已载的结构事实（`P-06`）。
10. **列参数**：在节点章节内同时列出输入栏与输出栏，每项形如 `` - `参数名`：类型描述；来源为 X `` 或 `` - `参数名`：类型描述；去向为 X ``；参数名匹配 `^[A-Z][A-Z0-9_]*$` 且不与任何节点标识符重名，无参数时该栏显式写「无」（`P-07`）。
11. **递归展开**：角色为子流程蓝图型的节点，在其章节内先绘本节点的子流程图，再以该子图为输入按本册同一套规则为其每个节点写章节；章节层级随嵌套加深一级，`P-01` 至 `P-07`、`P-11` 递归适用，展开到某层不再含子流程蓝图型节点时该分支结束（`P-08`）。

## 高频改写

- 主图内联了某节点的内部步骤，改为把该节点取子流程蓝图型形状，内部步骤移入其章节的子流程图。
- 主图章节内出现第二张图，改为把该图移入它所属节点的章节并删去对主图的重复。
- mermaid 之外的图（插图、截图、表格、纯文本箭头）改为 mermaid 围栏承载；非图内容的围栏信息串改为该内容的语言标识。
- 节点章节标题取描述名或俗称，改取该节点的标识符。
- 节点章节复述图内已载的出边存在与指向，改为只写该条件的判定语义。
- 节点改名后残留指向旧标识符的边，改为同步更新边端点与章节标题。
- 仅写输入栏或仅写输出栏，改为两栏齐备，无参数的一栏写「无」。
- 参数名与节点标识符重名或与它处不一致，改为全文按同一名字对齐。

## 自检

- 首行是 H1，全文 H1 恰有一行。
- H1 之后的首个内容块是自然段落，且该段落不夹在 H1 与目标段之间的其它块里。
- 首个 h2 章节内 mermaid 围栏恰为一个，且除该围栏外不含其它内容块。
- 同一张图内没有重名的描述名，边的端点都指向本图节点。
- 每个节点沿出边都能命中结束型节点，无出口的环已逐一点名。
- 主流程图每个节点的标识符在后续章节标题中出现且仅出现一次，章节正文不含 mermaid 围栏。
- 每个节点章节的输入栏与输出栏都在位，无参数处写「无」。
- 子流程图出现在其节点章节内、早于该子图的节点章节。
