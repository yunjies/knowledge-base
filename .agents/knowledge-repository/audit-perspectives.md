# 源码审核的默认视角清单

## 1. 视角清单

### AP-01 必要性与范畴

- **scope**: 源码中每一处抽象、选项、防御分支与公开导出面
- **动作**: 核对每处抽象、选项、防御分支与公开面与其当前消费方
- **产出物**: 消费方清单
  - **形态**: 逐项记录，每项含 {抽象或导出名, 位置引用, 消费方位置引用}
  - **判定口径**: 每个导出名都在其所属模块或层的调用点检索中取回至少一处消费方；取不回者列入候选删除
  - **语义判据**: 该消费方是否落在当前生产路径上——仅测试内部使用的消费方不足以为公开面提供存在理由
  - **判定边界**: 公开面的层次与命名是否恰当由 AP-13 判定

### AP-02 意图与规格一致性

- **scope**: 源码中每一处对外声明，声明取类型、契约文档、用例名与错误文字
- **动作**: 比对每处行为与其声明
- **产出物**: 声明与实现比对表
  - **形态**: 逐项记录，每项含 {声明来源, 从声明抽取的断言, 校验位置}
  - **判定口径**: 每条从声明抽取的断言都有对应的可执行校验，且该校验在声明被违反时转红
  - **语义判据**: 声明承诺的行为是否正是实现所做的事——命名承诺未兑现即判定分叉
  - **判定边界**: 跨模块或跨包接口两侧的一致性由 AP-03 判定

### AP-03 接口与契约双侧

- **scope**: 跨模块、跨进程与跨包的接口两侧
- **动作**: 比对接口两侧的常量、类型与错误语义
- **产出物**: 双侧契约比对记录
  - **形态**: 逐项记录，每项含 {契约项, 一侧取值, 另一侧取值, 判定值}
  - **判定口径**: 两侧的共享常量与类型逐项比对无差异
  - **语义判据**: 错误、取消与归属语义在两侧是否等价——取值相同而语义不同的项判为不一致
  - **判定边界**: 单侧内部的类型正确性由静态类型检查承担

### AP-04 数据与状态

- **scope**: 源码中每一处可变状态、共享可变对象与持久化格式
- **动作**: 核对每处可变状态的所有权、不变量与持久化格式
- **产出物**: 状态不变量记录
  - **形态**: 逐项记录，每项含 {状态载体, 不变量谓词, 守护断言位置}
  - **判定口径**: 每条不变量都有守护断言，且该断言在注入违反该不变量的状态转移时转红
  - **语义判据**: 非法状态是否可被构造表示——可表示者判为缺陷，不因未被触发而豁免
  - **判定边界**: 状态变更之间的时序竞态由 AP-07 判定

### AP-05 控制流与算法

- **scope**: 源码中每一处分支、比较、数值运算与边界裁剪
- **动作**: 探测每个分支的边界值、数值域与边界裁剪
- **产出物**: 边界矩阵
  - **形态**: 逐项记录，每项含 {分支位置, 边界类型, 输入取值, 期望结果, 用例位置}
  - **判定口径**: 边界矩阵的每一格都有用例覆盖，取值含极值、空值、恰好等于上限与多字节输入
  - **语义判据**: 比较与裁剪的语义是否符合契约——截断位置落在字符边界而非字节边界
  - **判定边界**: 错误输入的拒绝路径由 AP-06 判定

### AP-06 错误与故障传播

- **scope**: 源码中每一条拒绝路径与部分失败的恢复路径
- **动作**: 注入失败并沿每条拒绝路径追到执行该拒绝的操作
- **产出物**: 拒绝路径记录
  - **形态**: 逐项记录，每项含 {拒绝条件, 执行拒绝的操作, 可观测信号}
  - **判定口径**: 每条拒绝路径都产出可观测信号，且该路径在用例注入失败时被走到
  - **语义判据**: 错误归属是否正确、重试是否幂等——吞错与 fail-open 判为缺陷
  - **判定边界**: 失败信号的可诊断程度由 AP-12 判定

### AP-07 并发与时序

- **scope**: 源码中每一处异步初始化、重入点、取消点与 await 前后的状态依赖
- **动作**: 对异步初始化、重入、取消与 await 期间的失效构造时序
- **产出物**: 时序用例集
  - **形态**: 逐项记录，每项含 {时序前提, 交错次序, 期望终态, 用例位置}
  - **判定口径**: 每个时序用例在真实调度下稳定复现，重复运行不出现结果漂移
  - **语义判据**: 取消与所有权移交是否彻底——await 期间状态被替换后原续体是否仍写入
  - **判定边界**: 句柄与监听器的释放完整性由 AP-08 判定

### AP-08 资源与生命周期

- **scope**: 源码中每一处句柄、监听器、工作线程、缓存与副作用登记
- **动作**: 核对每处资源的装配与拆卸
- **产出物**: 资源守恒记录
  - **形态**: 逐项记录，每项含 {资源类型, 装配位置, 拆卸位置, 计数}
  - **判定口径**: 装配与拆卸前后的资源计数相等，每处装配都有对应的拆卸处
  - **语义判据**: 释放是否完全停稳——拆下引用而底层仍存活者判为未释放
  - **判定边界**: 规模相关的资源增长由 AP-09 判定

### AP-09 性能与容量

- **scope**: 源码中每一处随输入规模增长的循环、遍历、分配与 IO
- **动作**: 按规模阶梯实测复杂度、分配与 IO
- **产出物**: 规模阶梯实测数据
  - **形态**: 逐项记录，每项含 {被测路径, 规模取值, 耗时或分配量, 增长阶}
  - **判定口径**: 实测增长阶不高于该路径设计预期的阶，且探针在改动前后取同一规模序列
  - **语义判据**: 该退化是否落在用户可感知的路径上——不可感知路径的退化不据此判为缺陷
  - **判定边界**: 功能正确性由 AP-05 判定

### AP-10 安全与信任边界

- **scope**: 源码中每一处信任边界、授权判定与外部输入入口
- **动作**: 演练每条攻击路径并对拒绝路径断言
- **产出物**: 攻击路径演练记录
  - **形态**: 逐项记录，每项含 {信任边界, 攻击手法, 期望拒绝, 用例位置}
  - **判定口径**: 每条拒绝路径都有用例，且在放开对应守卫时该用例转红
  - **语义判据**: 信任边界的划分是否与授权判定一致——fail-open 的默认分支判为缺陷
  - **判定边界**: 授权判定之外的输入校验由 AP-05 判定

### AP-11 测试强度与判别力

- **scope**: 用例中每一条守护断言与每一处门禁登记
- **动作**: 还原旧实现并确认守护断言转红
- **产出物**: 判别力自证记录
  - **形态**: 逐项记录，每项含 {断言位置, 注入的缺陷, 转红证据}
  - **判定口径**: 每条守护断言在注入它所守护的缺陷后转红；恒真断言、被放宽的断言与被跳过的用例计为缺口
  - **语义判据**: 断言的判别力是否覆盖它声称守护的命题——只证某用例通过而不证该用例覆盖该命题者判为缺口
  - **判定边界**: 用例的归位与配对完整性由 AP-16 判定

### AP-12 可观测性与可诊断性

- **scope**: 源码中每一处日志、指标、诊断文字与稳定可见字符串
- **动作**: 制造失败并仅凭产出定位根因
- **产出物**: 根因定位记录
  - **形态**: 逐项记录，每项含 {失败注入点, 产出, 定位到的根因, 定位所需信息}
  - **判定口径**: 每次失败都能仅凭日志、指标或诊断文字定位到唯一起因
  - **语义判据**: 静默降级是否被排除——失败被吞掉而产出仍报成功者判为缺陷
  - **判定边界**: 错误信号的传播路径由 AP-06 判定

### AP-13 结构与依赖

- **scope**: 源码中每一对模块间的依赖边与每一处导出符号
- **动作**: 机械抽取依赖图与导出面
- **产出物**: 依赖图与分层记录
  - **形态**: 逐项记录，每项含 {文件, 依赖方向, 所属层, 越界项}
  - **判定口径**: 依赖图中无跨层边、无环，且组合根在各侧唯一
  - **语义判据**: 抽象是否泄漏——下层概念出现在上层接口者判为泄漏
  - **判定边界**: 模块职责的归属由该工程的模块归属规则判定；单一文件内部构件之间的变更族分离由 AP-18 判定

### AP-14 可演进性与兼容性

- **scope**: 源码中每一处公开面、版本兼容层与弃用路径
- **动作**: 枚举公开面的消费方并核对变更的迁移路径
- **产出物**: 兼容性记录
  - **形态**: 逐项记录，每项含 {公开面项, 消费方清单, 变更类型, 迁移路径}
  - **判定口径**: 每个破坏性变更都附迁移路径与旧契约的兼容断言
  - **语义判据**: 兼容层的退场条件是否写明——无退出条件的兼容路径判为债务
  - **判定边界**: 公开面的当前消费方是否存在由 AP-01 判定

### AP-15 事实源一致性

- **scope**: 源码与文档中每一处对同一事实的多重表示
- **动作**: 比对同一事实的多处表示
- **产出物**: 多源比对记录
  - **形态**: 逐项记录，每项含 {事实, 各承载位置, 权威源, 差异}
  - **判定口径**: 同一事实的每处表示都能解析到同一权威源，且抄本随权威源同步
  - **语义判据**: 跨文档陈述同一事实的口径是否等价——各自自洽而并置冲突者判为缺陷
  - **判定边界**: 由设计导出的契约性常量不由本条判定

### AP-16 构建、测试与制品

- **scope**: 源码中每一处构建配置、锁文件、测试布局与发布物清单
- **动作**: 核对构建配置、锁文件、测试布局与发布物
- **产出物**: 构建面记录
  - **形态**: 逐项记录，每项含 {构建项, 声明, 实际产物, 判定值}
  - **判定口径**: 发布物的路径集合等于包清单的发布字段所列成员，且源代码目录下的每个源文件都有配对的测试文件
  - **语义判据**: 声明与实际发布物是否一致——发布面缺少声明项或多出未声明项均判为缺陷
  - **判定边界**: 构建产物的运行时行为由 AP-05 与 AP-07 判定

### AP-17 许可证、隐私与审计留痕

- **scope**: 工程内每一处组织与法规约束的对应物
- **动作**: 核对外在约束在工程内的落实情况
- **产出物**: 外在约束核对记录
  - **形态**: 逐项记录，每项含 {约束来源, 约束内容, 工程内对应物, 判定值}
  - **判定口径**: 每条约束的判定值取自 [审核事实记录的循环流程](notes/audit-record-loop-flow.md) 的 `REVERSE_VERDICT` 域，本条实际用到其中三种——可证缺陷仍在、可证已处理、证据不足无法判定
  - **语义判据**: 该约束是否落在事实源的论域内——组织决策与规范定案未落进工程者判为无法判定
  - **判定边界**: 判定值与保留集处置取 [审核事实记录的循环流程](notes/audit-record-loop-flow.md) 的 REVERSE_VERDICT

### AP-18 单文件构件分解与变更族分离

- **scope**: 源码中每一个其具名构件存在文件外消费方的文件
- **动作**: 逐具名构件取其文件外的消费方，解析出这些消费方所属的模块集合，再对任两个构件的模块集合取交
- **产出物**: 分解候选记录
  - **形态**: 逐项记录，每项含 {文件, 构件甲及其文件外消费方清单与模块集合, 构件乙及其文件外消费方清单与模块集合, 两模块集合的交集}
  - **判定口径**: 逐具名构件取其文件外的消费方文件集合，按该工程的模块归属记录解析为消费方模块集合，丢弃集合为空的构件；对余下构件两两求模块集合的交，交集为空的对各记一条候选记录，并列出该对的消费方清单以佐证；判定值即该交集是否为空，逐条可重算
  - **语义判据**: 该对的两个构件是否分属不同的变更族——改动其一是否会必然同步改动另一，必然同向者划掉该条；二者共用的私有构件若无法随任一侧移出，该对判为不可拆并写明阻碍；候选记录只是待裁的假设，交集为空不等于应当拆分
  - **判定边界**: 文件之间的依赖边、层级与环由 AP-13 判定；拆分后各文件应归属哪个模块由该工程的模块归属规则判定；文件体量本身不构成本条判据——行数多的文件不因此命中，行数少而承接多个变更族的文件照样命中

### AP-19 新视角准入

- **scope**: 一处候选的检查维度是否构成本册应新增的视角
- **动作**: 按序执行（步间有数据依赖）：
  - ① 指名该候选的判定对象，以及它命名的失效形态
  - ② 核验该失效形态具备非空的证据面，且判定值可复算
  - ③ 三项齐备者按本册既有的条目标题级别与字段集撰写条目；缺任一项者降级为待验证假设，不新增条目
- **产出物**: 准入结论
  - **形态**: 逐项记录，每项含 {候选维度, 它指名的判定对象, 它命名的失效形态, 该失效形态的证据面, 判定值可否复算}
  - **判定口径**: 判定对象与失效形态各自具名，且该失效形态有非空证据面、判定值可复算，三项齐备为准入；缺任一项即降级为待验证假设。准入后重跑 `.agents/skills/rule-card-writing/scripts/check-card.js`
  - **语义判据**: 该候选是否与既有视角判同一对象上的同一失效形态——同者并入既有视角，不新增条目
  - **判定边界**: 既有视角各自的判定对象与判据由该视角条目自身承载，不由本条判定；本条也不判定某一轮启用哪些视角，逐轮启用的集合取各轮自己的裁定
- **失败行为**: fail_loud
  - **行为**: 三项缺任一项时中止新增并点名所缺的那一项，不把它当作已准入的视角写进本册
