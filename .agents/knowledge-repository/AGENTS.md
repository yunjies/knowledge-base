# 跨项目知识库索引

本目录承载**跨项目可复用**的知识沉淀：其条文的命题脱离本工程仍成立，可随 `.agents/` 一并移植到别的工程。本工程的**专有**知识不在此列，其落点是工程根的 `knowledge-repository/`——两处按**复用范围**分工，不由内容主题分工。

本文档是本库的**索引层**：说明这里有哪些文档、各自何时读。**不要因为进入了本目录就通读全部**——每份文档在需要时才加载，此前只需本文档给出的定位信息。本目录**不在 DSH 的自动加载路径上**（运行时只沿会话工作目录的祖先链与被触碰文件的父目录链发现 `AGENTS.md`），故它靠工程根 `AGENTS.md` 的指针被引入。

## 什么内容放在这里

判据只有一条：**删去本工程的一切专有名词（源码路径、模块编号、构建配置、门禁路径）后，该条文是否仍成立且可执行。** 成立者住本库，不成立者住工程根 `knowledge-repository/`。

由此导出两条禁令：

1. **本库文档不得链接工程根知识库的文档**，也不得链接本工程的源码、测试与配置。此类链接在别的工程解析不到，会把可复用的条文绑死在当前工程上。跨库引用一律改为对**通用对象**的表述，或指向本库内的文档。
2. **同一条文只住一处**。条文移入本库后，工程根知识库不再保留其内容，只留指向本库的指针；反之亦然。两处各存一份会使它们随各自修订静默分叉，而两库之间没有一致性门禁。

本库可以链接 `.agents/skills/` 下的规范册与脚本——那是随 `.agents/` 一同移植的邻居，不属"工程专有"。

## 与工程根知识库的关系

工程根 `knowledge-repository/` 承载当前工程专有的地图、规则、判据与操作流程；工程根的知识库索引负责给出其文档入口与加载时机。本库不复制这些工程专有条目。

两库的**分工判据是复用范围**，不是内容主题：同一主题可以两侧都有文档，只要其条文分别落在不同的复用域。读者据文档所在的位置即可判断一条规则适用于谁，无须逐条阅读后自行推断。

## 撰写与修订的规范

新增或修订本目录文档时，行文、规则卡片字段、规范册构成与流程图结构分别遵循 `.agents/skills/` 下对应的技能。各工程自行决定文档守护的扫描面与可执行门禁；本库不写入某个工程的测试路径或工具命令。
