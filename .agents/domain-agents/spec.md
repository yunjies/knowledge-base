# 领域 agent 脚手架规范

## 1. 单领域 host-tool agent 约束

### DA-01 单领域边界
- **模态**: must
- **scope**: 领域 agent 模板及其具体实例
- **动作**: 为每个领域 agent 声明且只声明一个知识领域
- **产出物**: 可判定的领域实例定义
  - **形态**: 唯一领域标识及纳入、排除范围
  - **判定口径**: 每个实例有且只有一个非空领域标识，纳入与排除范围均已登记
  - **语义判据**: 任一知识条目是否可唯一归入该领域；存在两个合理归属时边界不成立

### DA-02 host tool 是知识入口
- **模态**: must
- **scope**: 领域 agent 获取领域事实或执行领域操作
- **动作**: 只调用该实例在宿主工具注册表中注册且已授权的工具
- **产出物**: 可追溯的工具操作
  - **形态**: 工具名、结构化参数、返回值及记录标识
  - **判定口径**: 每项领域事实均关联到已注册工具的结果；agent 指令不得授权直接遍历、搜索或读取知识存储
  - **语义判据**: 没有工具返回时，agent 是否仍能取得或断言领域事实；能则知识访问边界失效

### DA-03 行为由脚本承载
- **模态**: must
- **scope**: 领域知识读取、变更、策略查询与流程执行
- **动作**: 将可重复的操作逻辑实现为脚本函数，并由宿主工具定义调用
- **产出物**: 可调用的脚本接口
  - **形态**: 每个工具有具名 handler、输入 schema、输出 schema、权限检查及失败结果
  - **判定口径**: 每个模型可调用工具均由脚本 handler 实现；agent prompt 不承担路径解析、规则复制或状态转移逻辑
  - **语义判据**: 相同结构化输入是否由确定性代码给出同类结果；依赖提示词临场重建规则的操作不符合本条

### DA-04 行为数据结构化
- **模态**: must
- **scope**: 领域策略、知识索引、测试规范与 workflow 定义
- **动作**: 以具版本与 schema 的 JSON 数据承载可枚举、可判定的领域信息
- **产出物**: 可验证的结构化数据
  - **形态**: JSON 文档含 `schemaVersion`、领域标识及按 schema 定义的记录
  - **判定口径**: 数据可被 JSON parser 解析且通过对应 schema；工具实现不从自由文本推断权限、工具名称或 workflow 转移
  - **语义判据**: 若值可表示为有限枚举、记录、路径规则或状态转移，它是否仍被埋在 prompt 自由文本中；是则结构化不充分

### DA-05 权威知识按需读取
- **模态**: must
- **scope**: 以已有文档或配置为权威源的领域知识
- **动作**: 用结构化资源索引映射资源标识到单一权威源，并按任务调用检索工具
- **产出物**: 与权威源一致的读取结果
  - **形态**: 资源标识、权威源路径、请求范围、返回内容与源版本
  - **判定口径**: 资源索引只保存定位和解析元数据，不复制权威源正文；读取工具只接受登记的资源标识与有界查询参数
  - **语义判据**: 权威源更新后，工具结果能否在不改写第二份正文的情况下反映更新；不能则索引存放了事实副本

### DA-06 可读可写范围可查询且由脚本强制
- **模态**: must
- **scope**: 领域 agent 发起的知识读取与写入
- **动作**: 从结构化 path policy 返回可读、可写范围，并在每次 I/O 前执行路径归属检查
- **产出物**: 被策略约束的路径操作
  - **形态**: 每项路径规则含操作类型、允许路径或资源标识、拒绝条件及权威策略标识
  - **判定口径**: 未登记路径、越域路径、路径穿越和符号链接越界均在读取或写入前被拒绝；模型提供的原始路径不得直接交给文件系统
  - **语义判据**: 绕过 agent 指令后，工具 handler 是否仍无法读写策略外路径；能则策略仅为提示而非执行边界

### DA-07 测试规范可结构化检索
- **模态**: must
- **scope**: 领域 agent 需要为变更选择验证方式
- **动作**: 以结构化变更类别映射测试层、判据资源与执行入口，并按请求返回所需规范
- **产出物**: 可追溯的测试计划
  - **形态**: 变更类别、测试层、判据资源标识、验证入口与未覆盖边界
  - **判定口径**: 每个登记的变更类别均解析到至少一项测试判据；未登记类别明确返回未知而不默认跳过测试
  - **语义判据**: 返回的验证是否能证伪该变更的主要失败模式；只返回命令而没有相应判据不构成测试规范

### DA-08 review 由结构化 workflow 驱动
- **模态**: must
- **scope**: 领域 agent 执行需分阶段、需主 agent 编排的 review 流程
- **动作**: 按 workflow 数据验证当前阶段输入、返回下一阶段及其任务契约，并将语义审核工作委派给主 agent 管理的 subagent
- **产出物**: 可复算的 review 执行状态
  - **形态**: workflow 标识、阶段序列、阶段输入输出、完成状态、subagent 结果引用与最终判定
  - **判定口径**: 每次转移均符合 workflow 中登记的边；缺失必需产物、越序推进或失败状态均被拒绝
  - **语义判据**: 主 agent 是否持有跨领域和整体 verdict 的责任，领域 subagent 是否只提交本领域证据而不自授最终通过

### DA-09 知识 CRUD 经登记工具执行
- **模态**: must
- **scope**: 领域知识记录的创建、读取、修改与删除
- **动作**: 为 CRUD 分别提供结构化工具操作，并在写操作前校验领域、目标标识、权限与记录版本
- **产出物**: 可核验的知识记录变更
  - **形态**: 记录 ID、领域 ID、操作类型、版本、变更结果或拒绝原因
  - **判定口径**: 修改与删除必须指定唯一目标及预期版本；新增、修改、删除均产出可观察结果；并发过期写入不得覆盖新版本
  - **语义判据**: 变更结果是否与工具返回的记录及新版本一致；不得声称未由工具证实的持久化结果

### DA-10 失败时封闭拒绝
- **模态**: must
- **scope**: 数据损坏、资源未登记、授权不足、路径不符、版本冲突、工具异常或 workflow 输入缺失
- **动作**: 返回结构化失败结果并停止该次操作，不回退到直接文件访问或自由文本推断
- **产出物**: 可诊断的失败响应
  - **形态**: 稳定错误码、失败阶段、安全可公开的原因及已完成副作用
  - **判定口径**: 所有失败分支均返回错误而非成功值；拒绝发生在受保护 I/O 之前，或明确列出已经完成的副作用
  - **语义判据**: 调用者能否区分未执行、部分执行与已完成；无法区分时不得继续推进 workflow

### DA-11 工具只暴露当前实例能力
- **模态**: must
- **scope**: 领域 agent 的 Host Tool Registry 组合
- **动作**: 将实例工具注册在该 subagent 的作用域，并限制工具读取该实例的数据根与单一领域
- **产出物**: 隔离的工具可见面
  - **形态**: preset 中的工具声明、实例配置及工具执行期领域校验
  - **判定口径**: 无关 agent 看不到领域专属工具；修改调用参数中的领域标识不能扩大资源索引、path policy 或知识库范围
  - **语义判据**: 工具包被其他 preset 复用时，是否仍有执行期边界保护；仅依赖工具说明或隐藏 schema 不算隔离

### DA-12 通过可执行验收后才可加载
- **模态**: must
- **scope**: 主 agent 加载或编排领域 subagent 实例
- **动作**: 运行 schema、脚本 handler、工具注册契约与行为反例测试，并逐条映射 DA-01 至 DA-11 的证据
- **产出物**: 可复算的实例验收结果
  - **形态**: 规范条目、测试或宿主证据位置、运行结果及未验证边界
  - **判定口径**: DA-01 至 DA-11 均有验证；反例覆盖盲读、越域路径、越权 CRUD、陈旧版本、非法 workflow 转移和工具错误；失败项阻止加载
  - **语义判据**: 测试能否在对应约束被移除时转红；只检查文件存在、工具名称或提示词字面提及不构成行为验收
